Помощник для Python‑кода, который работает на вашем компьютере

Чат о коде, агент, который сам читает и правит файлы проекта и проверяет правки тестами, поиск по проекту и дообучение модели на ваших данных. Модель запускается локально: код не покидает компьютер, интернет нужен только чтобы её скачать.

Что нового в этой версии

Чат
Вопросы о коде с учётом вашего проекта и, если нужно, веб-поиска.
Агент
Находит нужные файлы, правит код и запускает тесты, пока правка не пройдёт. Перед первой правкой делает снимок проекта, так что изменения можно откатить.
Поиск по проекту
Индекс кода на вашем диске: модель находит нужное место по смыслу, а не только по словам.
Дообучение
QLoRA на ваших примерах, чтобы модель писала в стиле вашей команды. Нужна лицензия Pro и видеокарта NVIDIA.

Установка

  1. Распакуйте скачанный архив .7z, например бесплатным 7-Zip.
  2. Запустите FluxionBrowserLite.exe. Если Windows предупредит о неизвестном издателе, нажмите «Подробнее» и «Выполнить в любом случае».
  3. Мастер первичной настройки проверит компьютер. Модель скачайте на странице «Модели» или положите файл вручную, как описано ниже.

Что нужно компьютеру

  • Windows 10 или 11, 64 бит.
  • Память под модель: 7B занимает около 4,7 ГБ, 3B — около 2,2 ГБ.
  • Видеокарта не обязательна: модель работает на процессоре. С видеокартой NVIDIA ответы быстрее.

Модели

Программа скачивает модели сама на странице «Модели». Скачать вручную пригодится для компьютера без интернета: положите файл в папку %LOCALAPPDATA%\Fluxion\models или выберите его кнопкой «Импорт с диска…».

Как применить

  1. Скачайте файл пресета.
  2. В программе откройте «Обучение» и нажмите «Загрузить из файла…».
  3. Выберите датасет и нажмите «Начать обучение».

Свой пресет

Пресет — это небольшой JSON-файл. Формат и допустимые значения описаны в руководстве по дообучению. Программа проверяет каждый файл и принимает только поддерживаемые базовые модели.
