# Fluxion 0.14.0 — что нового

Fluxion больше не только про код. Теперь это локальный AI-помощник для кода,
текстов и документов: он читает ваши PDF, Word и Excel, пишет письма и
переводит, а модели можно брать любые — из каталога или по ссылке.

Подробный технический список — в `CHANGELOG.md`.

## Ответы по вашим документам

Поиск по проекту теперь читает не только код, но и **PDF, Word (.docx),
Excel (.xlsx), PowerPoint (.pptx) и CSV**. Выберите папку с договорами,
отчётами или таблицами на странице **«Проект»**, нажмите «Проиндексировать»
и спрашивайте: «какой срок оплаты в договоре с поставщиком?». Документы
остаются на вашем компьютере.

## Модели для текстов

В каталоге появились модели для писем, документов и переводов:
**Qwen2.5 1.5B и 7B** (бесплатно) и **Qwen2.5 14B** (Pro). Для кода
по-прежнему лучше модели Coder.

## Любая модель по ссылке

Кнопка **«Скачать по ссылке…»**: вставьте ссылку на модель в формате GGUF
с Hugging Face, выберите файл из списка (размеры видны сразу, подходящий
вариант подсвечен) и нажмите «Скачать». Загрузка идёт с докачкой и проверкой
контрольной суммы. Бесплатно для всех.

## Каталог обновляется сам

Новые модели появляются в списке без обновления программы: Fluxion берёт
каталог с сайта. На странице моделей появились **поиск и фильтры**: для кода,
для текстов, для слабых компьютеров, по видеопамяти и «Моя видеокарта».

## Удобнее

- **Выбор модели в чате**: «⚙ Настройки чата» → «Модель» показывает все
  скачанные модели и переключает их без перезапуска.
- **Новое меню «Модели»** вверху окна: каталог (Ctrl+M), облачная модель по
  API и обучение. На боковой панели остались «Чат» и «Проект».
- **Звук, когда ответ готов.** Выключается в «⚙ Настройки чата».

## Перед обновлением из исходников

Выполните `pip install -r requirements.txt`: для чтения PDF добавлен пакет
`pypdf`. Готовую программу это не касается.
