# Fluxion 0.22.0 — российские провайдеры облачной модели

**Российские провайдеры в «Облачной модели по API» (Pro).** Кроме OpenRouter, Groq, Together и OpenAI теперь есть **ProxyAPI, VseGPT, AITunnel, BotHub, GigaChat (Сбер), YandexGPT (Yandex Cloud) и Cloud.ru**: оплата в рублях картой РФ, работают без VPN. Выберите провайдера — адрес и пример модели подставятся сами, а под формой появится подсказка, где взять ключ.

- **GigaChat:** вставьте ключ авторизации из developers.sber.ru — токен доступа Fluxion получает и обновляет сам. Нужны «Сертификаты Минцифры» (gosuslugi.ru/crt).
- **YandexGPT:** в имени модели замените `<folder_id>` на ID каталога Yandex Cloud.
- В «Инструкции» (F1) — новая страница «Облачная модель по API» с пошаговой настройкой и разбором ошибок.

**Исправлено:** программа могла аварийно завершиться при закрытии окна чата или инженерного калькулятора.

**На сайте** рядом с версией для Windows появилась ссылка на Fluxion Mobile.

Программа одна, со всеми инструментами: Pro включается ключом в ней же. Если Fluxion установлен через `FluxionSetup.exe`, обновление придёт в один клик.

Как купить Pro — на [сайте, в разделе «Цены»](https://djonros.github.io/Fluxion/#pro).

Подробный технический список — в `CHANGELOG.md`.
