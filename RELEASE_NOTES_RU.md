# Fluxion 0.26.0 — связь с телефоном

**Связь с телефоном.** Инструменты → «Связь с телефоном…». Fluxion Mobile теперь может спрашивать ваш компьютер по домашней сети Wi-Fi. Первой так работает вкладка «Ремонт» в Fluxion Mobile 0.7.1: фото сломанной техники разбирает модель на компьютере, в интернет ничего не уходит.

- Модель для фото — Qwen2.5-VL 7B, около 5,5 ГБ, скачивается из окна одной кнопкой. С видеокартой от 8 ГБ фото разбирается за секунды, на процессоре — за минуту-две. Вместо неё подойдёт Ollama с моделью `qwen2.5vl:7b`.
- Модель загружается при первом фото и выгружается через 10 минут без фото, чтобы не занимать память.
- На текстовые вопросы с телефона отвечает та же модель, что и в чате Fluxion.

Компьютер отвечает, только пока Fluxion открыт, и только телефону с кодом сопряжения из окна. «Новый код» отключает старые телефоны. При первом включении Windows спросит про брандмауэр — разрешите доступ в частных сетях. Как подключить телефон — в «Инструкции», раздел «Связь с телефоном».

Программа одна, со всеми инструментами: Pro включается ключом в ней же. Если Fluxion установлен через `FluxionSetup.exe`, обновление придёт в один клик.

Как купить Pro — на [сайте, в разделе «Цены»](https://djonros.github.io/Fluxion/#pro).

Подробный технический список — в `CHANGELOG.md`.
