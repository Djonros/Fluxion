# Fluxion 0.17.0 — что нового

Fluxion берёт на себя рутину конструкторского отдела: по готовой сборке
КОМПАС-3D он собирает сводную ведомость, считает металлоёмкость, сварные швы,
площадь под покраску и трудоёмкость модели — и до оформления показывает, что в
модели исправить.

Подробный технический список — в `CHANGELOG.md`.

## Отчёты по сборке КОМПАС-3D

Меню **Инструменты → «Ведомость и металлоёмкость сборки…»**, выберите файл
`.a3d`. Сборка открывается только для чтения и закрывается без сохранения, а
если она открыта у вас — Fluxion её не закрывает. Отчёт — книга Excel в
`Документы\Fluxion CAD`:

- **Сводная ведомость** в виде дерева построения: позиции из спецификаций,
  разделы в порядке спецификации, подсборки сворачиваются.
- **Металлоёмкость** по материалу и сортаменту, со сверкой с массой изделия в
  КОМПАС.
- **Сварка** — швы находятся по стыкам деталей в модели: длина по контуру
  контакта, катет по наименьшей толщине (не больше 12 мм), масса металла шва
  с коэффициентом 1,2 и таблица сварки по катетам.
- **Покраска** — площадь под дробеструйную обработку и окраску без
  нержавейки, алюминия, оцинковки, пластиков и граней, скрытых в швах.
- **Трудоёмкость** — часы на модель по числу и сложности деталей, для нормы и
  премии. Нормы отдела — в файле `%APPDATA%\Fluxion\time_norms.json`.
- **Прочие изделия** — покупные: и те, что отнесены к «Прочим изделиям», и
  узнанные по наименованию (настил решётчатый, фонари, клапаны, фитинги, РВД,
  шины, оси).

## Нормоконтроль до оформления

Перед тем как сформировать отчёт, Fluxion показывает спорные места таблицей:
«покупное, а в модели в разделе «Детали»», «не задан материал — в спецификации
деталь будет отображаться неправильно», «нет обозначения», «нулевая масса».
Каждый пункт нужно отметить — пока не отмечено всё, кнопка «Сформировать
отчёт» недоступна. Отметки запоминаются для изделия, в следующий раз
спрашиваются только новые места. «Сталь 10» без сортамента — материал, который
КОМПАС ставит новой детали сам, — считается незаданным.

## Перед обновлением из исходников

Выполните `pip install -r requirements.txt`: для отчётов добавлен пакет
`openpyxl`. Готовую программу это не касается — всё нужное уже внутри.
