# Fluxion 0.18.0 — что нового

Fluxion теперь проверяет не только сборки КОМПАС-3D, но и чертежи AutoCAD,
сам исправляет типовые ошибки в модели, выгружает пакет DXF на лазер, отвечает
по документам со ссылкой на страницу и пишет служебки и письма вашим стилем.

Подробный технический список — в `CHANGELOG.md`.

## Нормоконтроль чертежей AutoCAD

Меню **Инструменты → «Нормоконтроль чертежа AutoCAD…»** или в чате
`/автокад путь\чертёж.dwg`. Чертёж DWG открывается копией, только для чтения
(в AutoCAD или через бесплатный ODA File Converter), DXF читается сразу; ваш
файл не меняется. Fluxion находит рамку и штамп, сам определяет ЕСКД или СПДС и
проверяет:

- пустые графы штампа и масштаб в штампе против рамки или видового экрана;
- масштабы по ГОСТ 2.302, шрифты и высоты текста по ГОСТ 2.304;
- объекты на слое 0, цвет и тип линии не «по слою», Defpoints, пустые слои;
- размеры с вписанным вручную числом, потерянные внешние ссылки, объекты за
  рамкой.

Замечания нужно отметить в окне, отчёт сохраняется в Excel.

## Сборки КОМПАС-3D: исправить прямо в модели

В окне «Перед оформлением отчёта» появились кнопки:

- **«Исправить в модели (N)…»** — переносит покупные изделия в «Прочие
  изделия» спецификации их сборок.
- **«Задать материал (N)…»** — материал или сортамент для деталей без
  материала выбирается в справочнике «Материалы» КОМПАС-3D.

Fluxion покажет список правок и файлы, которые изменятся, спросит согласия и
перед правкой сделает резервную копию каждого файла в папку «Резервные копии
Fluxion» рядом с ним. Сборку нужно закрыть в КОМПАС-3D.

Ещё в отчёте по сборке:

- **Модели из других проектов и общих библиотек** — новое предупреждение: если
  компонент взят, например, из `…\Сибирь Трейлер 2016-2020\733322\…` или из
  `…\Покупные\…`, в строке виден путь, двойной щелчок по нему показывает файл
  в папке. Если так и задумано — отметьте, отметка запомнится для изделия.
- **Ссылки на модели**: обозначения в Excel, строки окна замечаний и ссылки
  в чате открывают деталь или сборку.
- Раздел каждого компонента берётся из спецификации его сборки, поэтому
  клапаны и фитинги из «Прочих изделий» больше не числятся покупными «в
  Деталях».

## Пакет на лазер (Pro)

Меню **Инструменты → «Пакет на лазер (DXFka)…»**: развёртки всех листовых
деталей сборки — с подсборками, исполнениями и локальными деталями — в DXF
1:1 без рамки и текстов, разложенные по папкам толщин. Ход виден в чате, в
конце — сколько DXF по каждой толщине и ссылка на папку.

## Мой стиль письма (Pro)

Служебные и пояснительные записки, письма заказчикам — вашей манерой, без
дообучения и видеокарты. **Инструменты → «Мой стиль письма…»**: добавьте 3–10
своих текстов, Fluxion опишет ваш стиль (обращения, обороты, подпись,
оформление), описание можно поправить. Потом включите **«✍ Мой стиль»** под
полем ввода и напишите, что нужно.

## Ответы по документам с источниками

Под ответом по вашим документам теперь список **«Источники»**: файл и
страница (у Excel — лист, у PowerPoint — слайд), щелчок открывает документ, а
в тексте ответа стоят номера [1], [2]. Документы, проиндексированные раньше,
проиндексируйте ещё раз — тогда у них появятся номера страниц.

## Датасет для обучения из своих документов

На странице «Обучение» — кнопка **«Из документов…»**: Fluxion прочитает ваши
PDF, Word, Excel и PowerPoint и составит пары «вопрос — ответ». Вы их
просматриваете, правите и сохраняете готовый датасет. Составить датасет можно
без видеокарты; само дообучение — Pro и видеокарта NVIDIA.

## Памятка

**Инструменты → «Памятка…»** — короткие инструкции по каждой возможности
прямо в программе, с поиском по тексту.

## Перед обновлением из исходников

Выполните `pip install -r requirements.txt`: для чертежей AutoCAD добавлен
пакет `ezdxf`. Готовую программу это не касается — всё нужное уже внутри.
