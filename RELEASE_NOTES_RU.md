# Fluxion 0.16.0 — что нового

Fluxion научился слушать и говорить. Вопрос можно надиктовать, ответ —
послушать, а в режиме «голосом без рук» вести весь разговор голосом, даже
строить детали в КОМПАС. А типовые детали теперь строятся за секунды, а не за
минуты.

Подробный технический список — в `CHANGELOG.md`.

## Голосовой ввод

Нажмите **микрофон** рядом с полем ввода (или **Ctrl+Пробел**) и говорите.
Запись остановится сама после паузы, распознанный текст появится в поле ввода —
его можно поправить и отправить. Чтобы отправлять сразу, включите
«⚙ Настройки чата» → «Отправлять сразу после диктовки».

Речь распознаётся на вашем компьютере моделью Whisper, звук никуда не
отправляется. Модель скачивается один раз: «Модели» → **«Распознавание речи»**
(Small — хороший русский на обычном процессоре, Base — для слабых компьютеров).
Бесплатно для всех.

## Ответы вслух

Кнопка с **динамиком** рядом с микрофоном — Fluxion читает ответы голосом
Windows. Под каждым ответом есть ссылка **«Озвучить»**, «Стоп» прерывает
чтение. Код вслух не читается, пути к файлам тоже, а размеры звучат
по-человечески: «100 на 96,15 мм».

## Голосом без рук

Кнопка с **наушниками** (или **Ctrl+Shift+Пробел**): Fluxion слушает, сам
отправляет сказанное, читает ответ и снова слушает. Скажите «Компас, втулка
30 на 20 длиной 50 из бронзы» — Fluxion построит деталь и назовёт массу, а если
чего-то не хватает, переспросит голосом. Выключается словом **«Стоп»** или той
же кнопкой.

## Детали в КОМПАС — за секунды

Типовые описания (втулка, пластина, фланец, гайка, вал, уголок, профили и
короба из листа) Fluxion теперь разбирает сам, без языковой модели: деталь,
которая раньше строилась около трёх минут, готова меньше чем за пять секунд.
Необычные описания по-прежнему читает модель. Функция в бете.

## Удобнее

- Значки микрофона и динамика — аккуратные линейные, в цветах темы.
- В светлой теме зелёные надписи (модель внизу окна, PRO) стали темнее и
  читаются на белом.

## Перед обновлением из исходников

Выполните `pip install -r requirements.txt`: для голоса добавлены пакеты
`faster-whisper` и `sounddevice`. Готовую программу это не касается — всё
нужное уже внутри.
