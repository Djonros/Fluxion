# Fluxion 0.12.1 — что нового

Подробный технический список — в `CHANGELOG.md`.

## Docker больше не запускается сам

Раньше при каждом запуске программа поднимала Docker Desktop ради
расширенного веб-поиска. Теперь по умолчанию работает **встроенный веб-поиск**,
которому Docker не нужен. Расширенный поиск через SearXNG включается по
желанию: меню **Правка → «Расширенный веб-поиск (SearXNG в Docker)»**. Выбор
запоминается, а выключение возвращает встроенный поиск и останавливает
контейнер.

## Обучение стало понятнее

- **«Дополнительные настройки»** на странице «Обучение» раскрываются
  нормально: поля больше не сжимаются, у каждого понятная подпись и подсказка.
- **Дообученная модель появляется в программе** — в списке «Модель» в чате под
  названием, которое вы указали. Раньше она попадала только в Ollama.

## Исправлено

- Агент из окна программы работал с лимитом 8 шагов вместо 15 — теперь 15.
- При выключенном расширенном поиске агент больше не сообщает, что веб-поиск
  недоступен.
- Без лицензии Pro облачный API заменяется встроенным движком, а не Ollama.
- Начали работать настройки, которые были описаны в документации:
  `SEARXNG_URL` и файл `config/.env`.

## Документация

Руководство пользователя, README и вся документация сверены с программой и
переписаны там, где устарели. Руководство пользователя теперь описывает работу
в программе, а не только в командной строке.

## Если вы обновляетесь с 0.11 или раньше

- Расширенный каталог моделей в Pro: 7B в точности Q8_0, 14B и 32B.
- Лицензия активируется файлом ключа: кнопкой, перетаскиванием или одной
  кнопкой, если файл лежит в «Загрузках».
- Загрузка модели больше не застревает с ошибкой «416».
