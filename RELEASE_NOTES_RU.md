# Fluxion 0.31.0 — деталь по чертежу в «Компасе»

**Деталь по чертежу в «Компасе».** В диалоге «/компас» к сообщению можно приложить DXF или DWG — и модель заполнит шаблон по настоящим размерам чертежа: пластины, фланцы и подобные детали получаются без пересказа словами. Из файла читаются габарит, контур (замкнутая полилиния, отрезки или наибольшая окружность для круглой детали), отверстия группами «⌀D — N шт.» с центрами, размеры (линейные, ⌀, радиусы, углы) и надписи — сводка подставляется в описание один раз. Чертежей можно несколько; «/компас» без текста, но с чертежом тоже работает; битый файл не роняет запрос — он вернётся строкой в проблемах. DWG читается через AutoCAD или ODA File Converter, DXF — напрямую.

Программа одна, со всеми инструментами: Pro включается ключом в ней же. Если Fluxion установлен через `FluxionSetup.exe`, обновление придёт в один клик.

Как купить Pro — на [сайте, в разделе «Цены»](https://djonros.github.io/Fluxion/#pro).

Подробный технический список — в `CHANGELOG.md`.
