# Fluxion 0.21.0 — установщик, обновление в один клик и выбор языка

**Установщик FluxionSetup.exe.** Скачайте, запустите — готово. Права администратора не нужны: Fluxion ставится для вашего пользователя, появляется в меню «Пуск» (ярлык на рабочем столе — по желанию) и удаляется как обычная программа. Если Windows покажет предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае». Портативная версия без установки — по-прежнему архив `.7z`.

**Обновление в один клик.** Fluxion сам проверяет обновления раз в день и, когда выходит новая версия, показывает, что в ней нового. Кнопка «Обновить сейчас» скачивает установщик, проверяет его контрольную сумму, закрывает программу, ставит новую версию и запускает её снова. Версию можно пропустить, а автоматическую проверку — выключить. Обновление в один клик работает в копии, поставленной установщиком: эту версию поставьте через `FluxionSetup.exe`, дальше — в один клик.

**Ваши данные — отдельно от программы.** Чаты, индексы документов, журналы и настройки теперь хранятся в `%LOCALAPPDATA%\Fluxion`, рядом с моделями, и не теряются при обновлении. При первом запуске новая версия сама переносит их из папки прежней версии (старая папка остаётся на месте). Для флешки — пустой файл `portable.txt` рядом с программой: тогда всё хранится в её папке, как раньше.

**Выбор языка интерфейса** — «Вид» → «Язык / Language»: русский, английский, украинский, белорусский, казахский, испанский и французский. Язык меняется после перезапуска, программа предложит его сама.

**«О Fluxion»** теперь открывается: версия, ссылка на сайт и папка с вашими данными. Кнопка в окне новой версии ведёт на страницу загрузки сайта.
