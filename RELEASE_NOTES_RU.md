# Fluxion 0.12.3 — что нового

Подробный технический список — в `CHANGELOG.md`.

## Обучение заработало на видеокарте

- **PyTorch с CUDA больше не подменяется**: при установке окружения обучения
  пакет unsloth тянул за собой PyTorch без поддержки видеокарты, и обучение
  падало с «Unsloth cannot find any torch accelerator». Теперь ставится сборка
  для CUDA, а после установки и перед каждым запуском программа проверяет, что
  PyTorch видит видеокарту.
- **Кнопка «Переустановить окружение»** на странице «Обучение»: если окружение
  ставилось прошлыми версиями, нажмите её один раз.
- **Видно, что обучение идёт**: полоса прогресса и строка «Обучение идёт ·
  12 мин 05 с · последняя строка журнала — 8 с назад». Долгий шаг без вывода
  (загрузка модели) теперь не спутать с зависанием.
- **Окружение хранится в `%LOCALAPPDATA%\Fluxion`** и переживает обновление
  программы и перенос её в другую папку. Повреждённое окружение (ошибка «No
  pyvenv.cfg file») программа распознаёт и предлагает переустановить.
- **Понятные ошибки в журнале**: вместо «Команда завершилась с кодом 1» —
  причина (`Причина: …`); исчезли `&quot;`, служебные HTTP-строки и
  предупреждения библиотек.
- **Обучение не падает после загрузки модели**: тренер собран под новую
  версию библиотеки trl, которая ставится в окружение.
- **7B-модель помещается в 8 ГБ видеопамяти**: пресет `low` обучает на
  последовательностях по 1024 токена, а модель чата на время обучения
  выгружается из памяти. Если памяти всё же не хватит, программа подскажет, что
  закрыть или какую модель поменьше выбрать.
- **Датасеты не только в ChatML**: кроме `messages` понимаются ShareGPT
  (`conversations`), Alpaca (`instruction` / `input` / `output`) и пары
  `prompt`/`completion`, `question`/`answer`, `вопрос`/`ответ`,
  `problem`/`solution`, `input`/`output`. Для большого файла (больше ~20 000
  примеров) программа предложит взять первые 5 000. Неподходящий
  файл виден сразу — «формат не распознан» рядом с полем, — а не после загрузки
  модели.
- Обучение больше не падает с «'charmap' codec can't decode»; индикаторы
  загрузки не забивают журнал тысячами строк.
- HF-тренер больше не падает из-за отсутствующего FlashAttention.
- Обучение не запускается из папки архиватора: программа объясняет, что её
  нужно распаковать.

## Агент

- **Тесты в готовой программе**: агент сам находит Python, в котором есть
  pytest (сначала системный, затем окружение Fluxion), а если его нет нигде —
  ставит pytest в окружение Fluxion. Заглушка Python из Microsoft Store
  пропускается.
- **Агент не ходит по кругу**: если он несколько шагов подряд повторяет одно и
  то же действие, работа останавливается с понятным объяснением.
- **Режим «План»**: план сохраняется только после успешного ответа, а модель
  читает каждый файл один раз и сразу выдаёт нумерованный список шагов.

## Прочее

- **Индексация проекта** больше не пишет «Ollama недоступна»: программа берёт
  скачанную модель BGE-M3 со страницы «Модели».
- **Без чёрных окон консоли**: git, pip, winget и Python запускаются скрыто;
  Python 3.12 для обучения ставится для текущего пользователя, без запроса прав
  администратора.
- **Цены и покупка Pro**: на сайте появился раздел «Цены», в окне лицензии —
  кнопка «Купить Pro…». Ключ Pro покрывает все версии, вышедшие в течение года
  с даты его выдачи; эти версии остаются Pro навсегда.
