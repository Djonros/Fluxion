# Fluxion 0.11.0 — что нового

Подробный технический список — в `CHANGELOG.md`.

## Пресеты обучения из файла

- На странице «Обучение» появилась кнопка **«Загрузить из файла…»**. Пресет
  выставляет тип обучения, число эпох, ограничение на число примеров и базовую
  модель; выбор встроенного пресета в списке отменяет файл.
- Готовые пресеты: **«Экономный»** (от 6 ГБ видеопамяти), **«Стандартный»**
  (8–12 ГБ) и **«Быстрая проверка»** — одна эпоха на 200 примерах, чтобы
  убедиться, что обучение запускается, прежде чем тратить часы.
- Программа строго проверяет каждый файл: только известные параметры в
  допустимых пределах и только поддерживаемые базовые модели Qwen2.5-Coder.
  Пресет из интернета не может подставить чужую модель, способную выполнить
  код на вашем компьютере.
- Свой пресет — небольшой JSON-файл, формат описан в руководстве по
  дообучению.
