# Чат
<!-- раздел: Чат и документы | инструмент: - -->
## Для чего

Вопросы, тексты, письма, переводы, вопросы по коду проекта — в одном окне.

## Как запустить

Страница **«Чат»** — главный экран программы.

## Пошагово

1. Напишите вопрос и нажмите **Enter** («Отправить»). **Shift+Enter** — новая строка: поле растёт до восьми строк, дальше прокручивается. Длинный текст можно вставить целиком — он не обрежется.
2. Команды в начале сообщения: `/компас …` — деталь в КОМПАС, `/автокад путь` — нормоконтроль чертежа, `/архив …` — вопрос к архиву КД, `/расчёт …` — инженерный калькулятор.
3. **Ctrl+Enter** — отправить сообщение агенту (он читает файлы проекта).
4. Меню **⋮**: «Новый чат», «Экспорт чата в .md…», «Забыть проект».
5. **«Забыть проект»** (меню ⋮ или «Проект»): новый чат, в котором модель ни на что не ссылается — ни на файлы проекта, ни на прошлые сообщения; «Мой стиль» выключается. Ничего не удаляется: индекс остаётся на диске. Чтобы вернуть проект, выберите папку: «Проект» → «Выбрать папку…».

## Что получится

Ответ появляется по мере набора. Беседы сохраняются в списке чатов слева.

## Если не получается

- «Движок не подключён» — скачайте модель (Ctrl+M).
- Fluxion отвечает на языке вопроса: спросите по-русски — ответит по-русски.
- Ответ ссылается на файлы, которые к вопросу не относятся, — «Забыть проект».
- В адресной строке встроенного браузера запрос ищется в DuckDuckGo; через свой SearXNG — только если включён «Правка» → «Расширенный веб-поиск».
