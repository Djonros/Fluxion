# Архив КД
<!-- раздел: Архив КД | инструмент: archive | pro -->
## Для чего

Ответы по архиву конструкторской документации со ссылками на файлы: «из какого материала боковой лонжерон 714094», «где применяли лист 09Г2С после 2020».

## Как запустить

Меню **Инструменты → «Архив КД (Pro)…»**; вопросы — в чате: `/архив вопрос`.

## Пошагово

1. «Добавить папку…» — папки архива.
2. «Распознавать сканы» — встроенным распознаванием Windows (нужен русский языковой пакет).
3. **«Обновить индекс»**. Первый раз 30 тысяч файлов — около часа; можно остановить и продолжить позже.
4. Потом «Обновить индекс» читает только новые и изменённые файлы — минуты.
5. В чате: `/архив материал поперечины 714094`.

## Что получится

Под ответом — «Источники», щелчок открывает файл. Читаются КОМПАС-3D (обозначение, материал, масса, «Разработал», дата, состав) без запуска КОМПАС, PDF, Word, Excel, PowerPoint, старые .doc и .xls, DXF, сканы.

## Если не получается

- Номер изделия (имя папки) и годы в вопросе сужают поиск: «в 2016», «после 2019», «2016–2018».
- Поиск по словам: спрашивайте словами из документов — «лонжерон», «09Г2С», обозначением.
- DWG читаются при установленном ODA File Converter. Технические требования с поля чертежа КОМПАС видны только из PDF-копий.
