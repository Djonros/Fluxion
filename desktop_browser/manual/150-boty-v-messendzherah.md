# Боты в мессенджерах
<!-- раздел: Чат и документы | инструмент: bots -->
## Для чего

Спросить Fluxion с телефона — из Telegram, MAX или ВКонтакте: вопрос, расчёт, деталь в КОМПАС, отчёт по сборке, пакет на лазер. Бот работает на вашем компьютере, пока Fluxion открыт: сервер не нужен, порты открывать не надо.

## Как запустить

Меню **Связь → «Боты в мессенджерах…»**. Когда бот включён, в строке состояния появляется кнопка **«Боты: Telegram ✓»** — по ней то же окно.

## Пошагово

1. Получите токен бота:
   - **Telegram** — напишите @BotFather: `/newbot`, имя, адрес бота; он пришлёт токен.
   - **MAX** — бота создаёт @MasterBot; пока это доступно организациям, проверенным на платформе MAX для бизнеса.
   - **ВКонтакте** — в сообществе: Управление → Работа с API → «Создать ключ» с доступом к сообщениям и документам; там же включите Long Poll API с событием «Входящее сообщение» и включите «Сообщения» сообщества.
2. Вставьте токен на вкладке мессенджера, нажмите **«Проверить»** — Fluxion скажет имя бота или что не так.
3. Если Telegram не открывается, укажите HTTP-прокси: `http://адрес:порт`.
4. Отметьте **«Включить бота»**, добавьте **папки, открытые для ботов** — только из них бот берёт сборки и файлы — и нажмите **«Сохранить»**.
5. Напишите боту. Незнакомому человеку бот отвечает только кодом из 6 цифр. Введите код в окне **«Подтвердить»** — с этого момента бот ему отвечает. Убрать человека — «Убрать из списка».
6. Чтобы бот отвечал без вас, отметьте **«Запускать Fluxion свёрнутым при входе в Windows»**.

Команды бота:

| Команда | Что делает |
|---|---|
| просто вопрос | ответ, как в чате программы; голосовое сообщение тоже |
| `/расчёт шов катет 6 длиной 200, сила 30 кН` | инженерный калькулятор |
| `/компас втулка 30 на 20 длиной 50, бронза` | деталь в КОМПАС-3D, файл .m3d в ответ |
| `/архив рама 600.000` | поиск по архиву КД (Pro) |
| `/отчёт Рама 600.000`, `/смета …` | ведомость и металлоёмкость или себестоимость в Excel (Pro) |
| `/лазер Рама 600.000` | DXF развёрток по толщинам архивом .zip (Pro) |
| `/сравнить Рама изм1 ; Рама изм2` | что изменилось между версиями (Pro) |
| `/заявка Рама × 2 ; Стол × 5` | что закупить (Pro) |
| `/файл Рама.pdf` | прислать файл из папок бота |
| `/статус`, `/новый`, `/уведомления`, `/отмена`, `/помощь` | состояние, новый разговор, сообщать о концах заданий в программе |

Сборку можно указать полным путём или именем файла — бот ищет её в своих папках.

## Что получится

Ответы приходят в мессенджер, файлы — документами. Разговоры с ботом сохраняются в истории чатов Fluxion с пометкой мессенджера и имени: «[Telegram · Иван] …». Присланные боту файлы — в `Документы\Fluxion\Из мессенджеров`.

## Если не получается

- **«Токен не принят»** — токен скопирован не полностью или бот удалён: возьмите новый.
- **«Telegram недоступен»** — нет сети или Telegram закрыт: укажите HTTP-прокси.
- **Голосовые не распознаются** — скачайте модель распознавания речи (меню «Модели» → «Распознавание речи»); для голосовых Telegram, MAX и ВКонтакте нужен ещё ffmpeg в PATH.
- **«Функция Pro»** — отчёт, смета, лазер, сравнение, заявка и архив работают с Pro; вопросы, расчёты и детали в КОМПАС — бесплатно.
- **Отчёт по сборке не спрашивает про предупреждения**: в отчёте из бота они помечены «не проверено» — отметьте их в программе.
- **В пакете на лазер «Пропущено»** — деталям нужна рука в КОМПАС: сделайте их из программы.
- Сообщения и файлы проходят через серверы мессенджера. Не пересылайте через бота то, что нельзя выносить с завода.
- MAX проверен только на тестовом сервере: если «Проверить» не проходит, напишите нам.
