# Первый запуск и модели
<!-- раздел: Начало работы | инструмент: models -->
## Для чего

Fluxion работает на модели, которая лежит у вас на компьютере. Без неё чат и инструменты, которым нужна модель, не отвечают.

## Как запустить

Меню **Модели → «Скачать и выбрать модели…»** (Ctrl+M). При первом запуске то же предлагает мастер настройки.

## Пошагово

1. Откройте страницу «Модели».
2. Для обычной работы скачайте **Qwen2.5 Coder 7B** (4,7 ГБ) или, для писем и документов, **Qwen2.5 7B**. Для слабого компьютера — 3B или 1.5B.
3. Дождитесь загрузки: если связь оборвётся, нажмите «Скачать» ещё раз — загрузка продолжится.
4. Модель подключится сама. Переключить модель — **«⚙ Настройки чата» → «Модель»**.
5. Для голоса скачайте там же «Распознавание речи», для поиска по смыслу в проекте — BGE-M3.

## Что получится

Внизу окна, в строке состояния, видно, какая модель работает и готова ли она.

## Если не получается

- Мало места: модели хранятся в `%LOCALAPPDATA%\Fluxion\models`, удалить ненужную можно на той же странице.
- Медленно отвечает: возьмите модель поменьше или облачную модель по API (Pro) — внизу страницы «Модели».
