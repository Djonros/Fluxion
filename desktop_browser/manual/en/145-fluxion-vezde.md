# Fluxion everywhere
<!-- раздел: Чат и документы | инструмент: - -->
## What it is for

Rewrite, shorten, translate or answer a text right where you write it: in Word, mail, a browser, 1C — without switching to the Fluxion window.

## How to start

Select text in any program and press **Ctrl+Alt+Space**. Fluxion must be open (minimized is fine).

## Step by step

1. Select text and press **Ctrl+Alt+Space** — a Fluxion window with that text appears next to it.
2. Press **Rewrite**, **My style** (Pro), **Shorter**, **Translate ▾**, **Explain** or **Reply** — or write in your own words: «more polite», «add the dates».
3. **«Replace the selection»** — the answer replaces the selection in that program. **«Copy»** — to the clipboard, **«To the chat»** — go on in the big window. **Esc** — close.

## What you get

An answer of the Fluxion model on this computer: the text does not go to the internet (unless a cloud model is chosen). The clipboard is given back as it was after pasting.

## If it does not work

- **The window is empty, «No selected text came»** — nothing is selected, or the program runs as administrator: Windows does not let other programs take text from it. Paste the text into the window yourself (Ctrl+V).
- **«The key is taken by another program»** — another program (the Claude app, for one) already holds Ctrl+Alt+Space; then «Fluxion everywhere» works with **Ctrl+Alt+Q**. Your own combination — the chat settings button (the gear) → «Fluxion everywhere».
- To turn it off — the same place, the box «The Fluxion window in any program by a key».
