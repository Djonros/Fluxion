# Answers from documents with sources
<!-- раздел: Чат и документы | инструмент: project -->
## What it is for

So that Fluxion answers from your documents and code and shows where the answer comes from: «what is the payment term in the contract with the supplier?».

## How to start

The **«Project»** page → **«Choose…»** (a folder) → **«Index»**.

## Step by step

1. Choose a folder with contracts, reports, spreadsheets or code.
2. Press «Index». The first time the search model BGE-M3 is downloaded (about 1.3 GB).
3. Ask in the chat as usual.

## What you get

The answer has numbers [1], [2] after the facts, and under it **«Sources»**: the file and the page (for Excel — the sheet, for PowerPoint — the slide). A click opens the document.

## If it does not work

- PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx) and CSV are read. Scans without text, password-protected files and files over 50 MB are skipped.
- No page numbers — the documents were indexed before version 0.18: press «Index» again.
- For a large archive of KOMPAS drawings — «Design archive» (Pro).
