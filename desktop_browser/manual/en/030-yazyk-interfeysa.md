# Interface language
<!-- раздел: Начало работы | инструмент: - -->
## What it is for

The menus, buttons, tool windows and hints of Fluxion can be shown in another language. Russian, English, Ukrainian, Belarusian, Kazakh, Spanish and French are available.

## How to open it

Menu **View → «Язык / Language»**. The item is named in both languages so that you can find it whatever language is chosen.

## Step by step

1. Open the menu **View → «Язык / Language»**.
2. Choose a language: **Русский**, **English**, **Українська**, **Беларуская**, **Қазақша**, **Español** or **Français**.
3. Fluxion asks whether to restart now. Press **«Yes»** and the program opens again in the new language. If you press «No», the language changes at the next start.

## What you get

The menus, buttons, windows and messages of the program are in the chosen language. The choice is remembered.

## If it does not work

- Some text is still in Russian: Excel reports, standards check remarks, calculator results and some pages of this manual exist only in Russian for now.
- The model's answers do not depend on the interface language: Fluxion answers in the language of the question.
- The program did not restart by itself: close it and open it again.
