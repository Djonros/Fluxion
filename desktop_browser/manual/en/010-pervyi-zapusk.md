# First start and models
<!-- раздел: Начало работы | инструмент: models -->
## What it is for

Fluxion runs on a model stored on your computer. Without one the chat and the tools that need a model do not answer.

## How to start

Menu **Models → «Download and choose models…»** (Ctrl+M). On the first start the setup wizard offers the same.

## Step by step

1. Open the «Models» page.
2. For everyday work download **Qwen2.5 Coder 7B** (4.7 GB), or **Qwen2.5 7B** for letters and documents. For a weak computer — 3B or 1.5B.
3. Wait for the download: if the connection drops, press «Download» again — it continues where it stopped.
4. The model is connected by itself. To switch models — **the chat settings button (the gear) → «Model»**.
5. For voice download «Speech recognition» on the same page; for search by meaning in a project — BGE-M3.

## What you get

The status bar at the bottom of the window shows which model is working and whether it is ready.

## If it does not work

- Not enough space: models are kept in `%LOCALAPPDATA%\Fluxion\models`; a model you do not need can be deleted on the same page.
- Answers are slow: take a smaller model or a cloud model via API (Pro) — at the bottom of the «Models» page.
