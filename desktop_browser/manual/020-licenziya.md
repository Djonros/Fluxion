# Лицензия Pro
<!-- раздел: Начало работы | инструмент: license -->
## Для чего

Pro открывает инженерные инструменты (отчёты по сборкам, нормоконтроль, пакет на лазер, архив КД), «Мой стиль письма», агента с правкой файлов, дообучение, большие и облачные модели.

## Как запустить

Меню **Помощь → «Лицензия…»** или значок **FREE/PRO** внизу справа.

## Пошагово

1. Купить: кнопка **«Купить Pro…»** в окне лицензии или раздел «Цены» на сайте.
2. Ключ приходит файлом `.key`.
3. **«Загрузить файл ключа…»** или перетащите файл в окно лицензии. Можно вставить и текст письма целиком.

## Что получится

Pro включается сразу, без перезапуска и без интернета: ключ проверяется на вашем компьютере.

## Если не получается

- Окно лицензии показывает, до какой даты ключ покрывает новые версии. Более новая версия без продления работает как бесплатная.
- Ключ не принимается — напишите на почту из раздела «Цены» на сайте, приложите файл ключа.
