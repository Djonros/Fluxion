# Облачная модель по API
<!-- раздел: Агент и обучение | инструмент: models | pro -->
## Для чего

Чат и агент отвечают через модель провайдера в облаке: быстро даже на слабом компьютере, без скачивания весов. Кроме зарубежных OpenRouter, Groq, Together и OpenAI есть российские: ProxyAPI, VseGPT, AITunnel, BotHub, GigaChat (Сбер), YandexGPT и Cloud.ru — оплата картой РФ, работают без VPN.

## Как запустить

Меню **«Модели» → «Облачная модель по API…»** (раздел внизу страницы «Модели»).

## Пошагово

1. Выберите провайдера — адрес API подставится сам, под формой появится подсказка, где взять ключ.
2. Вставьте ключ из личного кабинета провайдера.
3. Нажмите **«Список моделей»** и выберите модель (или впишите её имя).
4. **«Проверить связь»**, затем отметьте «Использовать облачную модель вместо локальной» и **«Сохранить»**.

## Что получится

Чат и агент работают через выбранную модель, в строке состояния у имени модели — «(облако)». Вопросы и фрагменты кода уходят провайдеру, токены оплачиваются у него.

## Если не получается

- GigaChat: вставьте **ключ авторизации** (не Client Secret) — токен на 30 минут Fluxion получает и обновляет сам. Ошибка сертификата — установите «Сертификаты Минцифры» с gosuslugi.ru/crt. Для ключей юрлиц задайте `FLUXION_GIGACHAT_SCOPE=GIGACHAT_API_CORP` (или `GIGACHAT_API_B2B`).
- YandexGPT: в имени модели замените `<folder_id>` на ID каталога, ключ — API-ключ сервисного аккаунта с ролью `ai.languageModels.user`.
- ProxyAPI и VseGPT: модель пишется с вендором — `openai/gpt-4o-mini`, а не `gpt-4o-mini`.
- 401 — ключ не принят; 402 — пополните баланс у провайдера; 404 — проверьте имя модели.
