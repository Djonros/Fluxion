# Датасет из документов
<!-- раздел: Агент и обучение | инструмент: dataset -->
## Для чего

Составить датасет «вопрос — ответ» для дообучения по вашим документам: ГОСТам, стандартам предприятия, инструкциям.

## Как запустить

Страница «Обучение» → кнопка **«Из документов…»**.

## Пошагово

1. Добавьте файлы или папку: PDF, Word, Excel, PowerPoint, txt, md.
2. Выберите, сколько вопросов составлять на фрагмент (около 3000 знаков).
3. **«Составить вопросы»**. Для пробы поставьте «Фрагментов не больше» 3–5.
4. Просмотрите таблицу: ответ исправляется прямо в ней, неудачную пару снимите галочкой.
5. **«Сохранить датасет…»** — файл .jsonl сам подставится в поле датасета.

## Что получится

Файл .jsonl для дообучения. Закрыли окно — при следующем открытии продолжите с того же места.

## Если не получается

- На процессоре медленно: модель 7B — 2–5 минут на фрагмент; с облачной моделью (Pro) — секунды.
- Датасет можно собрать на любом компьютере, а обучать там, где есть видеокарта NVIDIA.
