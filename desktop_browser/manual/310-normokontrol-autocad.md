# Нормоконтроль чертежа AutoCAD
<!-- раздел: AutoCAD | инструмент: acad | pro -->
## Для чего

Проверить чертёж DWG или DXF так, как его проверил бы нормоконтролёр, по ЕСКД или СПДС.

## Как запустить

Меню **Инструменты → «Нормоконтроль чертежа AutoCAD (Pro)…»** или в чате `/автокад C:\путь\чертёж.dwg`.

## Пошагово

1. Выберите чертёж. DWG открывается копией только для чтения в AutoCAD или бесплатным ODA File Converter; DXF читается сразу.
2. Отметьте каждое замечание в окне — тогда сформируется отчёт. Отметки запоминаются для чертежа.

## Что получится

Отчёт `Документы\Fluxion CAD\<имя> - нормоконтроль.xlsx`: рамка и штамп, пустые графы, масштаб в штампе против рамки или видового экрана, масштабы ГОСТ 2.302, шрифты ГОСТ 2.304, слой 0, «по слою», Defpoints, размеры с вписанным числом, потерянные ссылки, объекты за рамкой.

## Если не получается

- DWG не открывается — запустите AutoCAD или установите ODA File Converter.
- Из консоли: `fluxion-acad.bat "чертёж.dwg"` (`--check` — только замечания).
