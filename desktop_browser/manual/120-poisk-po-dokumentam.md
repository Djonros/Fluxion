# Ответы по документам с источниками
<!-- раздел: Чат и документы | инструмент: project -->
## Для чего

Чтобы Fluxion отвечал по вашим документам и коду и показывал, откуда взят ответ: «какой срок оплаты в договоре с поставщиком?».

## Как запустить

Страница **«Проект»** → **«Выбрать…»** (папка) → **«Проиндексировать»**.

## Пошагово

1. Выберите папку с договорами, отчётами, таблицами или кодом.
2. Нажмите «Проиндексировать». Первый раз скачается модель поиска BGE-M3 (около 1,3 ГБ).
3. Спрашивайте в чате как обычно.

## Что получится

В ответе — номера [1], [2] после фактов, под ответом — **«Источники»**: файл и страница (у Excel — лист, у PowerPoint — слайд). Щелчок открывает документ.

## Если не получается

- Читаются PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx), CSV. Сканы без текста, файлы с паролем и больше 50 МБ пропускаются.
- Нет номеров страниц — документы проиндексированы до версии 0.18: нажмите «Проиндексировать» ещё раз.
- Для большого архива чертежей КОМПАС — «Архив КД» (Pro).
