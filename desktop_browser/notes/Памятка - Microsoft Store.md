# Памятка: как выпустить Fluxion в Microsoft Store (пошагово, для новичка)

Составлено 2026-11-07, дополнено 2026-11-08, для версии 0.28.0.

Опыт публикации не нужен. Идите по шагам сверху вниз. Если что-то на экране
выглядит иначе, сверяйтесь с английским названием кнопки в скобках: сайт
Microsoft иногда переводит кнопки по-разному.

## Коротко: что вообще происходит

1. Вы заводите **аккаунт разработчика** у Microsoft. Это бесплатно.
2. На сайте Microsoft для разработчиков, который называется **Центр партнеров**
   (Partner Center), вы **бронируете имя** программы, например «Fluxion».
3. Сайт выдаёт три служебные строчки — «паспорт» программы в Store. Вы вписываете
   их в один файл в папке Fluxion.
4. Вы **собираете пакет** — файл `.msix`. Это та же программа, только упакованная
   так, как требует Store. Сборка запускается двумя командами.
5. Вы **заполняете карточку** программы: описание, картинки, цену («бесплатно»),
   возрастной рейтинг. Тексты для неё уже готовы ниже, их можно копировать.
6. Нажимаете **«Отправить в Store»**. Microsoft проверяет программу от нескольких
   часов до 3 рабочих дней. Если всё в порядке, Fluxion появляется в Store.

Подписывать программу сертификатом не нужно: Store подписывает её сам и
бесплатно. Сайт, FluxionSetup.exe и портативный архив остаются как были:
Store-версия выходит рядом с ними.

## Шаг 1. Аккаунт разработчика (бесплатно, 15 минут плюс ожидание проверки)

1. Откройте <https://storedeveloper.microsoft.com>.
2. Войдите своей учётной записью Microsoft (той же, что в Windows или Outlook).
   Если её нет, там же нажмите «Создать».
3. На вопрос о типе аккаунта выберите **«Физическое лицо»** (Individual). Для
   физлица регистрация бесплатная. Тип «Компания» стоит 99 $, он не нужен.
4. Заполните имя, страну и адрес **как в паспорте**.
5. Подтвердите личность. Сайт попросит сфотографировать документ (паспорт) и
   сделать селфи. Удобнее всего с телефона: сайт покажет QR-код.
6. Ждите письма о проверке: от нескольких часов до нескольких дней.

> ⚠️ **Возможная проблема со страной «Россия».** На форуме Microsoft есть
> жалобы, что аккаунт с этой страной не проходит проверку, а Microsoft отвечает
> шаблонно. Официального запрета я не нашёл. Если откажут, напишите в поддержку
> из Центра партнеров (значок «?» → «Поддержка»). Указывать чужую страну нельзя:
> страна должна совпадать с документом.

Банковские реквизиты и налоговые анкеты **не нужны**: Fluxion в Store
бесплатный, деньги через Microsoft не идут. Pro по-прежнему продаётся на сайте.

## Шаг 2. Забронировать имя (5 минут)

1. Откройте <https://partner.microsoft.com/dashboard> и войдите тем же аккаунтом.
2. Слева или на главной странице выберите **«Приложения и игры»** (Apps and games).
3. Нажмите **«+ Новый продукт»** (+ New product) → **«Приложение MSIX или PWA»**
   (MSIX or PWA app).
4. Введите имя **Fluxion** и нажмите **«Проверить доступность»** (Check availability).
5. Если имя свободно, нажмите **«Зарезервировать имя продукта»** (Reserve product name).
   Если занято, попробуйте «Fluxion AI» или «Fluxion — AI для инженеров».
   Имя бронируется на 3 месяца: за это время нужно отправить программу.

Откроется страница программы. Её можно закрыть и вернуться к ней позже: она
лежит в «Приложения и игры».

## Шаг 3. Скопировать «паспорт» программы в файл (5 минут)

1. На странице программы слева откройте **«Управление продуктом»** (Product
   management) → **«Удостоверение продукта»** (Product identity).
2. Там будут три строки. Нужны:
   - **Package/Identity/Name**, вида `12345Djonros.Fluxion`;
   - **Package/Identity/Publisher**, вида `CN=1A2B3C4D-....`. Копируйте целиком, вместе с `CN=`;
   - **Package/Properties/PublisherDisplayName**, это ваше имя издателя.
3. В папке `C:\Users\PC\AI agent\installer\msix\` сделайте копию файла
   `store-identity.example.json` и назовите её `store-identity.json`.
4. Откройте `store-identity.json` Блокнотом и замените значения в кавычках:

   ```json
   {
     "IdentityName": "сюда Package/Identity/Name",
     "Publisher": "сюда Package/Identity/Publisher",
     "PublisherDisplayName": "сюда PublisherDisplayName",
     "DisplayName": "Fluxion",
     "Description": "Локальный AI-помощник инженера: чат, документы, код, КОМПАС-3D и AutoCAD."
   }
   ```

   `DisplayName` — имя, которое вы забронировали на шаге 2, буква в букву.
   Строку `_comment` можно удалить. Сохраните файл.

Это можете прислать мне: я проверю файл и соберу пакет сам.

## Шаг 4. Собрать пакет (около 15 минут, в основном ожидание)

1. Откройте папку `C:\Users\PC\AI agent` в Проводнике.
2. Щёлкните по адресной строке, наберите `powershell` и нажмите Enter. Откроется
   синее или чёрное окно, уже в этой папке.
3. Соберите программу (если свежая сборка уже есть, этот пункт можно пропустить):

   ```bat
   .\fluxion-build.bat --lite
   ```

4. Упакуйте её для Store:

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\build_msix.ps1
   ```

5. В конце будет зелёная строка «Готово». Файл лежит в
   `dist\artifacts\Fluxion-0.28.0.0-x64.msix` и весит около 250 МБ.

Если в конце жёлтая строка «пробный пакет с заглушками», значит скрипт не нашёл
`store-identity.json` (шаг 3). Такой пакет Store не примет.

## Шаг 5. Проверить пакет у себя (желательно, 15 минут)

Store поставит пакет только после своей подписи. Проверить его у себя заранее
можно так:

1. **Пуск → Параметры → Система → Для разработчиков** → включите **«Режим
   разработчика»** и согласитесь с предупреждением.
2. В том же окне PowerShell (шаг 4) выполните:

   ```powershell
   Add-AppxPackage -Register "dist\msix\layout\AppxManifest.xml"
   ```

3. В меню «Пуск» появится ещё один Fluxion. Запустите его и проверьте:
   - **Помощь → Проверить обновления** пишет, что обновляет Microsoft Store;
   - чат, скачивание модели, документы и голосовой ввод работают;
   - кнопки «Открыть папку» показывают файлы, а не пустую папку (см. ниже, «Риски», пункт 2).
4. Удалите пробную копию:

   ```powershell
   Get-AppxPackage *Fluxion* | Remove-AppxPackage
   ```

   Ваша обычная установка Fluxion при этом не пострадает. Режим разработчика
   потом можно выключить.

Можно также прогнать ту же проверку, что делает Store: **Пуск → Windows App
Cert Kit → Validate app package (Проверить пакет приложения)** → выберите
`.msix` → дождитесь отчёта. Если будут красные пункты, пришлите отчёт мне.

## Шаг 6. Заполнить карточку и отправить (30–60 минут)

На странице программы в Центре партнеров нажмите **«Начать отправку»**
(Start your submission). Появится список разделов. Заполните каждый.
Сохраняется всё само, поэтому можно прерваться.

### 6.1 «Цены и доступность» (Pricing and availability)

- **Рынки** (Markets): оставьте все страны.
- **Видимость** (Visibility): «Общедоступно» (Public audience).
- **Цена** (Base price): **«Бесплатно»** (Free).
- Если есть галочка о том, что программа использует **собственную или
  стороннюю систему оплаты**, поставьте её: Pro покупается на сайте. Для
  программ (не игр) Store это разрешает и комиссию не берёт.
- **Сохранить** (Save).

### 6.2 «Свойства» (Properties)

- **Категория**: «Производительность» (Productivity). Подкатегория, если спросит,
  любая подходящая. Можно выбрать и «Средства разработчика» (Developer tools).
- **URL-адрес политики конфиденциальности** (Privacy policy URL):
  `https://djonros.github.io/Fluxion/docs/privacy/`
- **Веб-сайт** (Website): `https://djonros.github.io/Fluxion/`
- **Контакты поддержки** (Support contact info): `djonros@gmail.com`
- **Системные требования**: минимум 8 ГБ ОЗУ и x64. Видеокарту можно не указывать.
- Остальные галочки не трогайте.
- **Сохранить**.

### 6.3 «Возрастные категории» (Age ratings)

Это анкета международной системы IARC. Отвечайте так:

- Категория программы: **«Приложение» / «Другое (не игра)»**, не «Игра».
- Насилие, секс, азартные игры, наркотики, ругательства **в самой программе**: **нет**.
- Обмениваются ли пользователи сообщениями друг с другом: **нет** (чат идёт с ИИ, а не с людьми).
- Есть ли неограниченный доступ в интернет: **да** (встроенный поиск в интернете).
- Передаётся ли местоположение: **нет**.
- Есть ли покупки цифровых товаров: **да** (ключ Pro продаётся на сайте).
- Создаёт ли программа содержимое по запросу пользователя (ИИ): **да**.

В итоге обычно выходит рейтинг 12+ или 16+. Это нормально.

### 6.4 «Пакеты» (Packages)

Перетащите в окно файл `dist\artifacts\Fluxion-0.28.0.0-x64.msix`. Подождите,
пока он загрузится и проверится: появится зелёная галочка. Если появится
красная ошибка, скопируйте её текст мне.

Ниже будет список «Семейства устройств» (Device families). Оставьте только
**Windows 10/11 Desktop**.

### 6.5 «Описания в Store» (Store listings)

Нужно два описания: **русское** и **английское**. Это те языки, что указаны в
пакете. Нажмите на язык и заполните поля. Готовые тексты ниже.

**Скриншоты** обязательны: хотя бы 1, лучше 4–5. Размер не меньше 1366×768.
Как сделать:

1. Разверните Fluxion на весь экран.
2. Откройте интересный экран: чат с ответом, ответ по документу со ссылкой на
   страницу, калькулятор с результатом, отчёт по сборке КОМПАС.
3. Нажмите **Win + Shift + S** → «Окно» → щёлкните по Fluxion. Снимок
   скопируется. Вставьте его в Paint (Ctrl+V) и сохраните как PNG.
4. Загрузите PNG в поле «Снимки экрана» (Screenshots). Подписи к скриншотам
   необязательны.

Логотип для карточки (Store logos) Store возьмёт из пакета. Можно загрузить и
отдельно: квадратный PNG 300×300 с прозрачным фоном из `assets\icon-256.png`
(увеличить до 300×300) или 1:1 из `icon-mark.png`.

### 6.7 Отправить

Вверху страницы отправки все разделы должны стать «Завершено» (Complete).
Нажмите **«Отправить в Store»** (Submit to the Store).

Дальше статус меняется сам: «Предварительная обработка» → «Сертификация» →
«Выпуск» → «В Store». Microsoft пришлёт письмо. Если программу не примут,
в письме будет причина. Пришлите её мне, разберёмся.

## Шаг 7. Как выпускать обновления потом

1. В коде поднимаете версию (`APP_VERSION`), как обычно.
2. Собираете пакет заново (шаг 4).
3. В Центре партнеров на странице программы нажимаете **«Обновить»** (Update)
   рядом с последней отправкой. Создастся копия прошлой карточки.
4. В разделе «Пакеты» удаляете старый `.msix` и загружаете новый. В «Описаниях»
   меняете «Новые возможности». Нажимаете «Отправить в Store».
5. Пользователи получат новую версию автоматически через Store.

Номер версии должен каждый раз расти: 0.28.0 → 0.29.0 и так далее. Скрипт сам
добавляет в конец «.0», как требует Store.

## Что уже сделано в коде (для справки)

- `core/app_paths.py`: `is_store_package()` определяет, что программа запущена
  из пакета Store. Для проверки без пакета есть `FLUXION_STORE_BUILD=1`.
- В копии из Store **нет встроенного обновления**: нет автопроверки, а «Помощь →
  Проверить обновления» показывает сообщение «обновляет Microsoft Store» и
  кнопку «Открыть Microsoft Store».
- В копии из Store **скрыт автозапуск с Windows** (настройки ботов): из пакета
  он не работает.
- `installer/msix/AppxManifest.xml` — описание пакета: обычная программа
  Windows, интернет, микрофон, языки ru-RU и en-US, Windows 10 1809+, x64.
- `installer/msix/store-identity.example.json` — образец для шага 3.
- `scripts/msix_assets.py` — значки и плитки для Store из `assets/icon-mark.png` (28 файлов).
- `scripts/build_msix.ps1` — сборка `.msix` (шаг 4). Нужен Windows SDK, на этом ПК он уже установлен.
- `tests/test_msix.py` — тесты.

## Риски на проверке и что с ними делать

1. **Установка программ из Fluxion.** Microsoft не любит, когда программа из
   Store скачивает и ставит другой исполняемый код (правило 10.2.2). Модели — это
   данные, их скачивать можно. Под вопросом:
   - мастер настройки ставит сторонние программы через winget (Docker, Git и другие);
   - окружение обучения ставит пакеты Python через pip.

   Если проверка откажет из-за этого, эти функции скрываются в Store-копии за
   несколько минут. Сейчас они **не скрыты**.
2. **Пустая папка в Проводнике.** Windows хранит новые файлы программы из Store
   в `%LOCALAPPDATA%\Packages\<имя пакета>\LocalCache\Local\Fluxion`, хотя
   сама программа видит их по обычному пути. Кнопка «Открыть папку» может
   показать пустую папку. Проверяется на шаге 5. При удалении Store-версии её
   данные тоже удаляются.
3. **Размер.** Lite занимает около 250 МБ, это в пределах лимитов. Full с CUDA в
   несколько раз больше. Начните с Lite.
4. **Имя.** Если «Fluxion» занято, выбирайте имя на шаге 2, до сборки: оно попадает в пакет.
