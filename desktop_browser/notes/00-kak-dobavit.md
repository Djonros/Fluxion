# Как устроена памятка

Каждый раздел памятки — отдельный файл `.md` в папке `desktop_browser/notes`.

- Первая строка `# Заголовок` — название раздела в списке.
- Порядок задаёт начало имени файла: `10-…`, `20-…`, `30-…`.
- Чтобы добавить раздел, положите новый файл в эту папку. Больше ничего менять не нужно, в сборку Lite папка попадает целиком.

Поиск сверху ищет по тексту всех разделов.
