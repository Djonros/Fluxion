# Источники в ответах по документам

Ответ по проиндексированным документам показывает, откуда он взят.

- В тексте ответа — номера вроде **[1]**, **[2]** после фактов.
- Под ответом — **«Источники»**: файл и место, например «[1] Договор поставки.pdf, стр. 3». У Excel — лист, у PowerPoint — слайд.
- **Щелчок по источнику** открывает документ.

Модель просят ставить номер фрагмента после каждого факта и не додумывать. Если источника нет — проверьте ответ сами.

## Старые документы

Документы, проиндексированные до версии 0.18, не знают номеров страниц. Нажмите **«Проиндексировать»** ещё раз — тогда у фрагментов появятся страницы, листы и слайды.
