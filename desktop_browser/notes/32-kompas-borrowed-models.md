# Модели из других проектов и библиотек (Pro)

Функция Pro: активировать — меню «Помощь» → «Лицензия…».

В окне «Перед оформлением отчёта» Fluxion отмечает компоненты, чьи файлы лежат не в папке изделия:

- **«Модель из другого проекта»** — например, кран из `…\Сибирь Трейлер 2016-2020\733322\…`.
- **«Модель из общей библиотеки»** — папки «Покупные», «Изделия», «Библиотека» (`…\Покупные\Camozzi\…`).

## Чем это опасно

- Если в том проекте модель изменят, изменится и ваше изделие.
- При передаче изделия (архив, аутсорс) этот файл не попадёт в папку изделия.

## Что делать

- В строке виден путь к файлу. **Двойной щелчок по пути** открывает его папку с выделенным файлом, по обозначению — саму модель.
- Если так и задумано (покупное из общей библиотеки, заимствованная деталь) — отметьте «Проверено». Отметка запоминается для изделия.
- Если нет — скопируйте модель в папку изделия и замените компонент в сборке.

## Что считается папкой изделия

Папка с номером изделия выше сборки: для `…\Архив\792720\Рабочка\Модель\792720.0000010 ….a3d` это `…\Архив\792720` (вместе с `Изм2`, `_Модель` и т. п.). Если такой нет — папка самой сборки.

Не отмечаются стандартные изделия и библиотеки КОМПАС, а у заимствованной подсборки — её внутренние детали (только она сама).
