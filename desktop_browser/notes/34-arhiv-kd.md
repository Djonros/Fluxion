# Архив КД (Pro)

Функция Pro: активировать — меню «Помощь» → «Лицензия…».

Fluxion ищет по архиву конструкторской документации и отвечает со ссылками на файлы: «из какого материала боковой лонжерон 714094», «где применяли лист 09Г2С 10 мм после 2020», «какие фитинги стоят в пневматике 792720».

## Что читается

- **КОМПАС-3D** (чертежи, спецификации, детали, сборки, фрагменты): обозначение, наименование, материал, масса, «Разработал», дата создания, у спецификаций и сборок — состав с позициями. КОМПАС не запускается, файлы только читаются.
- **PDF, Word, Excel, PowerPoint** — текст с номерами страниц.
- **Сканы** (картинки и PDF без текста) — встроенным распознаванием текста Windows, если включено. Нужен русский языковой пакет Windows.

Технические требования и надписи на поле чертежа КОМПАС так не читаются — их видно, если рядом лежит PDF чертежа.

## Настроить

1. Меню **Инструменты → «Архив КД (Pro)…»**.
2. **«Добавить папку…»** — папки архива (например, «Архив» и «Архив надстройки»).
3. **«Обновить индекс»**. Первый раз читается весь архив: 30 тысяч файлов — около часа. Можно нажать «Стоп» или закрыть окно: в следующий раз обновление продолжится с того же места.
4. Потом «Обновить индекс» читает только новые и изменённые файлы и убирает удалённые — это минуты.

Пропускаются копии: `.bak`, `~`, `$$$`, папки «Резервные копии Fluxion».

## Спрашивать

В чате: **`/архив вопрос`**. Под ответом — «Источники»: файлы архива, щелчок открывает файл.

- Номер изделия в вопросе (имя папки в архиве: 714094, 792720…) — ищется только в нём.
- Год: «в 2016», «после 2019», «до 2018», «2016–2018». Год берётся из даты создания файла КОМПАС (дата файла на диске — это дата синхронизации Яндекс Диска).
- Поиск идёт по словам: обозначения, материалы, наименования. Ищите словами, которые есть в документах: «лонжерон», «09Г2С», «723095.2801016».
