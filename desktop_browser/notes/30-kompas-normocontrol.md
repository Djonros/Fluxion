# Отчёт по сборке КОМПАС и нормоконтроль

Fluxion собирает по готовой сборке КОМПАС-3D сводную ведомость, металлоёмкость, сварку, покраску и трудоёмкость в один файл Excel.

## Как запустить

- Меню **Инструменты → «Ведомость и металлоёмкость сборки…»** и выбрать файл `.a3d`.
- Сборка открывается **только для чтения**, невидимо, и закрывается без сохранения. Ваша модель не меняется.
- Отчёт сохраняется в `Документы\Fluxion CAD`, ссылки на него и на модели появляются в чате.

## Окно «Перед оформлением отчёта»

Перед отчётом Fluxion показывает спорные места:

- покупное изделие не в разделе «Прочие изделия»;
- не задан материал (или стоит «Сталь 10» — материал КОМПАС по умолчанию);
- деталь или сборочная единица без обозначения, нулевая масса;
- модель взята из другого проекта или общей библиотеки (см. отдельный раздел).

Каждую строку нужно отметить «Проверено». Кнопка «Сформировать отчёт» включается, только когда отмечено всё. У покупных можно снять «Покупное», если это ваше изготовление: отчёт пересчитается.

Отметки **запоминаются для изделия**: в следующий раз спрашиваются только новые места. «Отмена — исправлю модель» тоже сохраняет сделанные отметки.

## Полезно знать

- Двойной щелчок по строке открывает модель в КОМПАС. Обозначения в Excel тоже кликабельны.
- Раздел каждого компонента берётся из спецификации его сборки — то, что будет напечатано.
- Полный список замечаний — на листе «Предупреждения» в отчёте, он открывается первым.
