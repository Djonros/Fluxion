# Датасет из ваших документов

Fluxion может сам составить датасет для дообучения по вашим документам: ГОСТам, стандартам предприятия, инструкциям, спецификациям.

**Где:** страница «Обучение» → кнопка **«Из документов…»** рядом с «Выбрать…».

**Как:**
1. Добавьте файлы или целую папку: PDF, Word, Excel, PowerPoint, txt, md.
2. Выберите, сколько вопросов составлять на фрагмент (фрагмент — около 3000 знаков текста).
3. Нажмите «Составить вопросы»: модель чата составит пары «вопрос — ответ».
4. Просмотрите таблицу: ответ можно исправить прямо в ней, неудачную пару — снять галочкой. В столбце «Источник» видно файл и фрагмент.
5. «Сохранить датасет…» — Fluxion предложит папку datasets в своих данных, а сохранённый .jsonl сам подставится в поле датасета.

Если закрыть окно, просмотр не потеряется: при следующем открытии продолжите с того же места.

**Без видеокарты:**
- Сбор датасета работает и на процессоре, но медленно: на модели 7B один фрагмент — 2–5 минут.
- Для пробы поставьте «Фрагментов не больше» 3–5 и «Вопросов на фрагмент» 2.
- С облачной моделью (Pro) фрагмент обрабатывается за секунды.
- Модель 1.5–3B быстрее, но вопросы и ответы у неё слабее.
- Само обучение QLoRA требует видеокарту NVIDIA. Датасет можно собрать на любом компьютере и перенести файл .jsonl туда, где есть видеокарта.

**Советы:**
- Сканы без распознанного текста пропускаются: сначала распознайте их (OCR).
- Перед обучением просмотрите хотя бы часть пар: модель иногда ошибается в цифрах.
