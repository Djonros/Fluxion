# Пакет на лазер (Pro)

Fluxion выгружает развёртки всех листовых деталей сборки КОМПАС-3D в DXF 1:1 — без рамки и текстов, по папкам толщин. Внутри работает ядро DXFka.

## Как запустить

1. Меню **Инструменты → «Пакет на лазер (DXFka)…»**.
2. Выбрать сборку `.a3d`.
3. Выбрать папку для DXF. Внутри создастся папка с именем сборки, а в ней — подпапки по толщинам в мм (`2`, `4`, `10`…).

Функция Pro: активировать — меню «Помощь» → «Лицензия…».

## Что попадает в пакет

- Детали из листового тела и детали с материалом «Лист …».
- Подсборки, исполнения и локальные детали — тоже.

## По ходу работы

- Ход выгрузки виден в чате.
- Если толщину не удалось определить, Fluxion спросит её (пустой ответ — пропустить деталь).
- Если нужен ручной шаг, откроется окно: проверьте вид в КОМПАС и нажмите «Продолжить», «Пропустить деталь» или «Остановить».
- В конце — сколько DXF по каждой толщине и ссылка на папку.
