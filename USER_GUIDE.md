# Fluxion — руководство пользователя

Как установить Fluxion, скачать модель и работать с чатом, агентом, поиском по
проекту, веб-поиском и дообучением. Технические подробности (настройки,
переменные окружения, API) — в [документации](https://djonros.github.io/fluxion/docs/).

---

## 1. Что такое Fluxion

Помощник для программирования на Python, который работает на вашем компьютере:

- **модель запускается локально** — код проекта и переписка не уходят в облако;
  интернет нужен только чтобы скачать программу и модель;
- отвечает на вопросы **по вашему проекту**: индексирует код и ищет по нему по
  смыслу;
- **агент** сам находит нужные файлы, читает код, запускает тесты и объясняет,
  что сломано; в Pro он ещё и исправляет код сам;
- ищет в **интернете**, когда вопрос требует свежей информации;
- модель можно **дообучить** на своих примерах (Pro).

Ollama и Docker не нужны: модель работает на встроенном движке llama.cpp.

**Что нужно компьютеру:** Windows 10 или 11 (64 бит), около 6 ГБ свободного
места под модели. Видеокарта не обязательна — модель работает на
процессоре, с видеокартой NVIDIA ответы быстрее. Для дообучения нужна
видеокарта NVIDIA от 6 ГБ памяти.

## 2. Установка

### Готовая программа

1. Скачайте **Fluxion Lite** на [странице загрузки](https://djonros.github.io/fluxion/).
   **Full** нужна, только если собираетесь дообучать модель без интернета.
2. Распакуйте архив `.7z` (например, бесплатным 7-Zip).
3. Запустите `FluxionBrowserLite.exe`. Если Windows предупредит о неизвестном
   издателе, нажмите «Подробнее» и «Выполнить в любом случае».

### Из исходников

```
fluxion-setup.bat      — один раз: окружение .venv, зависимости, движок llama.cpp
fluxion-desktop.bat    — запуск программы
```

Для других ОС и ручной установки — [docs/install.md](docs/install.md).

---

## 3. Первый запуск

1. Откроется **мастер первичной настройки**: он проверит компьютер и предложит
   **скачать модель** (около 4,7 ГБ). Загрузка докачивается, если оборвалась
   связь: нажмите «Скачать» ещё раз.
2. После загрузки модель подключится сама, перезапускать программу не нужно.
3. Внизу окна, в строке состояния, видно, какая модель работает и готова ли она.

Если мастер закрыт, модель можно скачать позже на странице **«Модели»**.

## 4. Чат

Страница **«Чат»** — основной экран.

- Пишите вопрос и нажимайте **«Отправить»** (или Enter). Fluxion сам решит,
  ответить сразу, поискать по коду проекта или в интернете.
- Кнопки-подсказки над полем — «Объясни этот проект», «Найди возможную
  ошибку», «Предложи рефакторинг».
- **«Модель»** вверху справа — выбор скачанной модели.
- Меню **⋮** рядом: «Новый чат», «Экспорт чата в .md…». Беседы сохраняются и
  переключаются в списке чатов.
- Код в ответах показывается блоками моноширинного шрифта.
- Флажок **«Агент: файлы»** у поля ввода передаёт задачу агенту (раздел 6):
  он увидит файлы проекта, а не только переписку.

Fluxion отвечает на языке вопроса.

## 5. Проект и поиск по коду

Чтобы Fluxion отвечал по вашему коду:

1. Страница **«Проект»** → **«Выбрать…»** — папка проекта.
2. **«Проиндексировать»**. Первый раз скачивается модель для поиска (BGE-M3,
   около 1,3 ГБ) — это займёт время. Дальше индекс обновляется быстро.

После этого вопросы вроде «где обрабатываются ошибки сети?» находят нужные
места по смыслу, а не только по словам. То же доступно в меню **Проект**.

---

## 6. Агент

Агент решает задачу по шагам: находит файлы, читает код, ищет по проекту,
запускает тесты и в конце пишет отчёт. Его ход виден по шагам.

- Страница **«Агент»**: опишите задачу и нажмите **«Запустить»**; **«Стоп»**
  прерывает работу. В **«⚙ Дополнительно»** — число шагов и разрешение на
  запись файлов.
- **Бесплатно агент только читает**: находит ошибку и объясняет её, но ничего
  не меняет.
- **В Pro** включите **«Разрешить запись файлов (Pro)»** (или меню **Агент**):
  агент сам исправит код и проверит правку тестами. Перед первой правкой он
  делает **снимок проекта**, не трогая ваши несохранённые изменения, так что
  всё сделанное можно откатить (в CLI — команда `/rollback`).
- Агент коммитит в git только файлы, которые менял сам, и никогда — `.env` и
  ключи.

Пример: «Тест tests/test_cart.py падает, найди и исправь ошибку».

## 7. Модели

Страница **«Модели»**: скачивание с докачкой, удаление, импорт.

| Модель | Размер | Доступ | Для чего |
|--------|--------|--------|----------|
| Qwen2.5 Coder 7B (Q4_K_M) | 4,7 ГБ | бесплатно | Модель по умолчанию |
| Qwen2.5 Coder 3B (Q4_K_M) | 2,2 ГБ | бесплатно | Для слабых компьютеров |
| BGE-M3 | 1,3 ГБ | бесплатно | Поиск по коду проекта |
| Qwen2.5 Coder 7B (Q8_0) | 8,1 ГБ | Pro | Точнее, нужно больше памяти |
| Qwen2.5 Coder 14B | 9,0 ГБ | Pro | Сильнее в сложных задачах |
| Qwen2.5 Coder 32B | 19,9 ГБ | Pro | Самая сильная, для мощных компьютеров |

- Переключить модель — список **«Модель»** в чате.
- **«Импорт с диска…»** — свой GGUF-файл; **«Импорт из Ollama»** — модели,
  уже скачанные в Ollama, без повторной загрузки.
- Модели хранятся в `%LOCALAPPDATA%\Fluxion\models`.

Подробнее — [docs/guides/models.md](docs/guides/models.md).

## 8. Веб-поиск

Веб-поиск работает сразу, **встроенным** способом: ничего устанавливать не
нужно, Docker не запускается.

**Расширенный поиск** через SearXNG даёт больше источников, но требует Docker
Desktop. Включается по желанию: меню **Правка → «Расширенный веб-поиск
(SearXNG в Docker)»**. Выбор запоминается; выключение возвращает встроенный
поиск и останавливает контейнер.

Состояние поиска видно на странице **«Состояние»** (внизу окна).

## 9. Дообучение (Pro)

Страница **«Обучение»** подстраивает модель под ваш код (QLoRA). Нужны
лицензия Pro и видеокарта NVIDIA от 6 ГБ.

1. **Окружение обучения** — программа установит его сама (в сборке Full — без
   интернета).
2. **Датасет** — файл `.jsonl` с примерами; кнопка «Выбрать…».
3. **Пресет** — «low» (6 ГБ, unsloth) или «standard» (8–12 ГБ), либо готовый
   пресет с сайта: **«Загрузить из файла…»**.
4. **«Начать обучение»**.

**«▸ Дополнительные настройки»** — базовая модель, название будущей модели и
адаптера, описание, сборка готовой модели (GGUF). Обычно их менять не нужно.

Готовая модель появляется в списке **«Модель»** в чате под указанным
названием. Для этой последней сборки нужна папка llama.cpp в переменной
окружения `LLAMA_CPP_DIR`; без неё сохраняется адаптер LoRA.

Подробнее и обучение из командной строки — [docs/guides/finetune.md](docs/guides/finetune.md).

## 10. Лицензия Pro

**Помощь → Лицензия…** (или значок **FREE/PRO** внизу справа).

| | Бесплатно | Pro |
|---|:---:|:---:|
| Чат, поиск по коду, веб-поиск, агент в режиме чтения | ✅ | ✅ |
| Модели 7B и 3B, встроенный движок, Ollama | ✅ | ✅ |
| Агент с правкой файлов | — | ✅ |
| Дообучение QLoRA | — | ✅ |
| Расширенный каталог моделей (7B Q8_0, 14B, 32B) | — | ✅ |
| Облачные модели через API | — | ✅ |

Ключ приходит файлом `.key`. Чтобы активировать:

- **«Загрузить файл ключа…»** или **перетащите файл** в окно лицензии;
- если файл лежит в «Загрузках» или на рабочем столе, окно само предложит
  **«Активировать ключ из файла …»**;
- или вставьте ключ в поле — подойдёт и текст письма целиком.

Ключ проверяется на вашем компьютере без интернета. Pro открывается сразу,
без перезапуска.

## 11. Обновления

**Помощь → «Проверить обновления…»** — сравнит вашу версию с последним
выпуском. Новая версия скачивается со [страницы загрузки](https://djonros.github.io/fluxion/).

## 12. CLI, VS Code, сервер

- **CLI** — `fluxion.bat` или `python -m cli.app`. Команды: `/help`, `/index`,
  `/agent`, `/rollback`, `/web`, `/license` и другие — полный список в
  [README](README.md#cli).
- **VS Code** — запустите `fluxion-server.bat`, установите расширение
  `fluxion-vscode.bat`, затем в VS Code: Ctrl+Shift+P → **Fluxion: Open Chat**,
  **Run Agent**, **Index Project**, **Server Status**.
- **Веб-версия** у владельца сервиса и self-hosted — [docs/deployment.md](docs/deployment.md).

## 14. Если что-то не работает

| Проблема | Что сделать |
|----------|-------------|
| Внизу «модель не скачана» | Страница «Модели» → скачать модель по умолчанию |
| Загрузка модели оборвалась | Нажмите «Скачать» ещё раз — продолжится с места остановки |
| Программа просит Ollama | Версия ниже 0.11.1 — обновитесь; или в `config/config.yaml` указано `backend: ollama` |
| Расширенный поиск не включается | Нужен запущенный Docker Desktop; без него работает встроенный поиск |
| Ответы не по проекту | «Проект» → «Проиндексировать» заново |
| Агент не меняет файлы | Бесплатно агент только читает; запись — в Pro |
| Ключ не активируется | Загрузите файл ключа кнопкой вместо копирования. Если срок ключа истёк или ключ выпущен для другого компьютера, попросите новый у продавца |
| Медленные ответы | Модель 3B, видеокарта NVIDIA или параметр `n_gpu_layers: -1` в config.yaml |

Больше — [docs/troubleshooting.md](docs/troubleshooting.md). Вопросы —
[GitHub Discussions](https://github.com/djonros/fluxion/discussions), ошибки —
[Issues](https://github.com/djonros/fluxion/issues).
