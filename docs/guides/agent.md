# ReAct-агент

Агент автономно решает задачи: планирует, вызывает инструменты, анализирует результаты и повторяет цикл до завершения.

## В приложении

Страница **«Агент»**:

1. Опишите задачу в поле сверху (например: «прочитай main.py и объясни, что он
   делает»).
2. Настройте опции: чекбокс **«Разрешить запись файлов (Pro)»** (эквивалент
   `--write`) и лимит итераций (1–50, по умолчанию 8).
3. Нажмите **Запустить** — каждый шаг рассуждений и вызовы инструментов видны в
   логе; **Стоп** прерывает выполнение.

Быстрый запуск из чата: включите чекбокс **«Агент: доступ к файлам»** в тулбаре
страницы «Чат» — следующее сообщение уйдёт агенту с инструментами проекта
(запись файлов по-прежнему только в Pro).

## Запуск

```
❯ /agent Fix the failing test in tests/test_parser.py
❯ /agent --write Add docstrings to all public functions in utils.py
```

!!! warning "Без флага `--write` агент работает в read-only"
    Запись файлов (`write_file`, `edit_file`) и git-операции разрешены только с `--write`.

## Инструменты

| Инструмент | Описание |
|------------|---------|
| `read_file` | Прочитать файл |
| `write_file` | Создать/перезаписать файл |
| `edit_file` | Точечное редактирование |
| `grep` | Поиск по кодовой базе |
| `run_tests` | Запустить pytest |
| `web_search` | Веб-поиск через SearXNG |
| `git_status` | Статус рабочего дерева |
| `git_diff` | Показать изменения |
| `git_commit` | Сделать commit |
| `finish` | Завершить задачу |

## Git safety

- **Auto-checkpoint** — перед каждой записью файла агент автоматически делает git-stash checkpoint
- **Rollback** — если задача провалилась, изменения можно откатить
- **Commit из агента** — финальные изменения фиксируются отдельным commit

## API

```bash
curl -X POST http://localhost:8765/api/agent/run \
  -H "Content-Type: application/json" \
  -d '{"task": "Fix the failing test", "allow_write": true}'
```
