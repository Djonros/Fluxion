# Детали в КОМПАС-3D (бета)

Fluxion строит деталь в КОМПАС-3D по описанию словами: модель разбирает текст,
выбирает шаблон и размеры, КОМПАС строит деталь и сохраняет её. Для деталей из
листа Fluxion строит ещё развёртку и сохраняет её в DXF для лазерной резки.

Это бета. Fluxion строит простые детали и гнутые листовые детали **по шаблонам**
(список ниже), а не произвольную геометрию и не сборки. Если описание не похоже
ни на один шаблон, деталь не построится — Fluxion скажет об этом в чате.

## Что нужно

- Windows 10 или 11 и установленный **КОМПАС-3D** (проверено на версии 24).
  Fluxion работает с ним через его COM-интерфейс; если КОМПАС не запущен,
  Fluxion запустит его сам.
- Модель для разбора описаний — та же, что в чате (локальная или облачная).
- Функция бесплатная и есть во всех сборках.

## Как пользоваться

**В чате** — сообщение, начинающееся с `/компас` (или `/kompas`):

```
/компас втулка 30 на 20 длиной 50, фаска 1, бронза
/компас уголок 50х30 из листа 2 мм, длина 100, 09Г2С
/компас короб 200х150, борт 30, лист 1 мм, оцинковка
```

**Из меню** — **Инструменты → «Деталь в КОМПАС…»**: если в поле ввода чата
есть текст, Fluxion возьмёт его, иначе откроет окно для описания.

Работа идёт в фоне, окно программы не зависает. В чате видно, какой шаблон
и какие размеры поняла модель и что взято по умолчанию, затем — путь к файлу,
масса детали, а для листовой — размер развёртки и путь к DXF.

### Уточняющие вопросы

Если в описании нет главного размера (например, длины втулки или наружного
диаметра фланца) или материала, Fluxion не строит сразу, а спрашивает одним
сообщением, чего не хватает:

```
Понял: втулка, наружный диаметр 30, внутренний диаметр 20.
Уточните: длина; материал (например: сталь 45, 12Х18Н10Т (нержавейка),
Д16Т (алюминий), латунь ЛС59-1, капролон; по умолчанию — Сталь 45).
```

Следующее сообщение в чате — ответ, писать `/компас` снова не нужно:
«длина 50, нержавейка». Ответ «по умолчанию» берёт стандартные значения,
«отмена» — не строить. Больше двух вопросов подряд Fluxion не задаёт: дальше
строит со значениями по умолчанию и пишет, какие взял. Второстепенное
(фаски, отступы отверстий) берётся по умолчанию без вопросов.

## Шаблоны

**Обычные детали:**

| Шаблон | Что можно задать |
|---|---|
| Пластина | длина, ширина, толщина; 4 отверстия по углам, центральное отверстие, отверстия в торцах, фаска по контуру |
| Фланец | наружный и внутренний диаметр, толщина, отверстия под болты на окружности |
| Втулка | наружный и внутренний диаметр, длина, фаски на торцах |
| Вал | ступени (диаметр и длина каждой), осевое отверстие, поперечное отверстие под штифт, фаски на торцах |
| Уголок | полки, толщина, ширина |
| Гайка | размер под ключ, отверстие, высота |

**Детали из листа со сгибами:**

| Шаблон | Что можно задать |
|---|---|
| Уголок гнутый | полки, угол между полками (по умолчанию 90°), отверстия в полках |
| Кронштейн-уголок | то же, по умолчанию по два отверстия ⌀9 в каждой полке |
| П-профиль (швеллер гнутый) | спинка, полки, отверстия в спинке и полках |
| Z-профиль | полки, стенка, отверстия в стенке |
| Лоток / короб | дно, высота бортов, 2 борта (лоток) или 4 (короб, углы открытые), отверстия в дне |
| Полка с отбортовкой | длина, глубина, отбортовка по одному или двум краям, отверстия |

Для листовых: толщина листа, внутренний радиус сгиба (по умолчанию равен
толщине), коэффициент нейтрального слоя K (по умолчанию — по таблице
Романовского для отношения r/t). Длины полок по умолчанию — **по наружной
стороне**; если написать «по внутреннему», Fluxion посчитает по внутренней.
В ответе всегда сказано, как взято.

## Развёртка и DXF

Для листовой детали КОМПАС сам строит развёртку, Fluxion измеряет её и
сохраняет рядом с деталью файл **«Имя — развёртка.dxf»**:

- простой DXF (R12), миллиметры, развёртка начинается в точке (0, 0);
- контур и отверстия — на слое **CUT**, линии сгиба — на слое **BEND**;
- без рамки, штампа и размеров чертежа — можно сразу отдавать на лазер.

Длина развёртки считается так же, как в КОМПАСе: прямые участки полок плюс
дуги сгибов по нейтральному слою, φ·(r + K·t). Ответ в чате даёт и расчётный
размер, и размер, который измерил КОМПАС.

## Материалы

У детали задаётся материал из каталога: КОМПАС записывает его в свойства
детали и считает массу, Fluxion показывает её в ответе. Материал узнаётся
в обычном тексте: «из стали 45», «нержавейка», «алюминий», «д16», «09г2с»,
«рифлёнка 4», «чечевица 5 мм». Незнакомый материал Fluxion переспросит, а не
подставит наугад.

В каталоге есть конструкционные стали, нержавеющие, алюминиевые сплавы,
латунь, бронза, чугун, капролон, фторопласт и листы с сортаментом толщин:
Ст3, 08пс, 09Г2С, оцинковка, 12Х18Н10Т, AISI 304, АМг2, АМг3, рифлёный лист
«чечевица» (ГОСТ 8568-77) толщиной 3, 4 и 5 мм. Если толщины нет в
сортаменте выбранного листа, Fluxion спросит и предложит ближайшие.

Масса рифлёного листа считается по массе 1 м² из таблицы; эти значения в
каталоге ориентировочные — сверьте их со своим ГОСТом или поставщиком.

### Свой каталог

**Инструменты → «Каталог материалов…»** показывает все материалы и даёт:

- **«Открыть файл каталога»** — ваш файл `%APPDATA%\Fluxion\materials.json`.
  Запись с тем же названием (`name`), что у встроенной, заменяет её; новые
  добавляются. Формат описан в начале встроенного каталога `cad/materials.json`.
- **«Импорт из Excel/CSV…»** — таблица со столбцами «название», «плотность»
  и по желанию «марка/ГОСТ», «толщины», «синонимы», «тип», «масса 1 м2».
  Строки с ошибками не ломают каталог: Fluxion пропустит их и перечислит.
- **«Обновить»** — перечитать файлы.

## Где лежат файлы

Детали сохраняются в `Документы\Fluxion CAD`. Существующие файлы Fluxion не
перезаписывает: новая деталь с тем же именем получает имя «Имя (2).m3d».
Построенная деталь остаётся открытой в КОМПАСе.

## Из командной строки

```
python -m cad "втулка 30 на 20 длиной 50"     # с вопросами в консоли
python -m cad --no-ask "втулка 30 на 20"      # без вопросов, по умолчанию
python -m cad --demo                           # все шаблоны на примерах
python -m cad --spec деталь.json               # готовый JSON
```

То же запускает `fluxion-kompas.bat`.

## Ограничения

- Только шаблоны из списка выше: не произвольная геометрия, не сборки,
  не чертежи с размерами.
- Отверстия в полках листовых деталей — только при сгибах на 90°.
- У короба углы открытые (без замыкания углов).
- Пока Fluxion строит деталь, КОМПАС сам отвечает «Нет» на свои вопросы
  вроде «Сохранить изменения?» — потом настройка возвращается как была.
- Модель иногда ошибается в размерах: проверяйте, что Fluxion понял, — это
  написано в ответе перед построением.
