# Лицензия Pro (десктоп)

Fluxion работает полностью бесплатно и офлайн. Часть продвинутых возможностей
закрыта **Pro-лицензией** — одноразовым ключом, который проверяется локально
(Ed25519), без сервера и без отправки данных куда-либо.

## Что бесплатно, что Pro

| Возможность | Free | Pro |
|---|:---:|:---:|
| Чат, RAG по коду, веб-поиск | ✅ | ✅ |
| ReAct-агент в read-only | ✅ | ✅ |
| Локальные бэкенды (llama.cpp, Ollama) | ✅ | ✅ |
| Агент с записью файлов (`/agent --write`) | 3 пробные правки | ✅ |
| Агент «без лимита» итераций | — | ✅ |
| QLoRA-дообучение (`finetune/train_*`) | — | ✅ |
| Расширенный каталог моделей: 7B Q8_0, 14B, 32B ([Модели](models.md)) | — | ✅ |
| API-бэкенд (облачные модели) | — | ✅ |
| VS Code extension, eval-бенчмарки, адаптеры из реестра | ✅ | ✅ |

Без Pro при запросе к Pro-фиче вы получите сообщение
`Pro feature ... /license activate <key>` — ядро продолжит работать в free-режиме.

## Активация

Ключ приходит файлом `.key` (или строкой в письме). Откройте окно лицензии —
кнопка **FREE/PRO** внизу справа или меню **Помощь → Лицензия…** — и выберите
удобный способ:

- **«Загрузить файл ключа…»** — выбрать присланный файл;
- **перетащить файл** ключа прямо в окно лицензии;
- если файл лежит в **«Загрузках»**, на **рабочем столе** или рядом с
  программой, окно само предложит **«Активировать ключ из файла …»** — одна
  кнопка;
- **вставить ключ** в поле: подойдёт и текст письма целиком, и ключ, который
  почтовая программа разбила на несколько строк.

Ключ проверяется подписью на вашем компьютере, без интернета: подделанный или
чужой (привязанный к другому ПК) ключ не активируется. После активации
Pro-возможности открываются сразу, без перезапуска.

Без лицензии страница «Обучение» и запись файлов агентом показывают подсказку
об активации; чат, RAG и read-only агент работают бесплатно.

## Пробные правки

Чтобы оценить агента с записью файлов до покупки, в программе есть **три
пробные правки**. Включите чип **«Агент: файлы»** в чате и дайте задачу: перед
каждым изменением файла появится вопрос

> Пробная запись: `src/app.py`. Разрешить? Осталось попыток: 3

- **«Разрешить»** — правка выполняется, счётчик уменьшается на единицу;
- **«Отменить»** — файл не меняется, попытка не расходуется; агент узнаёт, что
  запись отменена, и продолжает без неё.

Остаток виден в подсказке чипа и в плашке над полем ввода («Pro или триал:
осталось N пробных правок»). Когда попытки израсходованы, агент снова работает
только на чтение, а при включении чипа показывается обычная подсказка о Pro.
После активации лицензии подтверждения исчезают.

Счётчик хранится локально (`%APPDATA%\Fluxion\trial.json`; при запуске из
исходников — `data/trial.json`) и привязывается к компьютеру при первой
правке. Пробные правки действуют в программе; в CLI `/agent --write` требует
лицензию.

Актуальные цены, стартовая скидка и кнопка заявки — на
[сайте, в разделе «Цены»](https://djonros.github.io/fluxion/#pro); туда же
ведёт кнопка **«Купить Pro…»** в окне лицензии. Порядок простой: вы пишете на
почту из заявки, получаете реквизиты для перевода или счёт, после оплаты —
чек и файл ключа `.key`. Лицензия бессрочная и выдаётся на одного человека.
В CLI ключ активируется командой — можно передать и путь к файлу ключа:

```
❯ /license activate <ключ>

Activated PRO license for you@example.com
Expires: never (perpetual)      # или Expires: 2027-08-20 ... если лицензия срочная
```

Прочие команды:

| Команда | Что делает |
|---|---|
| `/license status` | текущий план, email, срок действия |
| `/license activate <key>` | активировать ключ или файл ключа (`/license activate C:\\Users\\you\\Downloads\\fluxion.key`) |
| `/license deactivate` | удалить локальную активацию |

Ключ хранится локально в `data/license.key`. Никакого «онлайн-телефона» нет:
подпись Ed25519 проверяется офлайн, публичный ключ вшит в код.

## Как это работает

- Ключ — это `base64(payload).base64(signature)`; payload — JSON
  `{email, plan, issued_at, expires?}` (без `expires` — бессрочная лицензия).
- Подпись проверяется публичным ключом владельца (`licensing/verifier.py`).
- Подделать ключ без приватного ключа владельца невозможно; дата истечения
  входит в подписанный payload и не редактируется.

## Для владельца (выпуск ключей)

Выпуск ключей — только у владельца приватного ключа, см. `OWNER_GUIDE.md`:

```bash
# бессрочная Pro-лицензия
python -m licensing.issuer --email customer@example.com

# годовая
python -m licensing.issuer --email customer@example.com --expires 2027-08-20
```
