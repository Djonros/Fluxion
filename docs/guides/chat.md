# Чат в приложении

Страница **Чат** — основной экран Fluxion: разговор с локальной моделью о вашем коде.

## Интерфейс

- **Подсказки** — кнопки над полем ввода («Объясни этот проект», «Найди возможную
  ошибку», «Предложи рефакторинг») подставляют готовый промпт.
- **Модель** — выпадающий список моделей для чата и агента (GGUF-модели из
  страницы «Модели», а на бэкенде Ollama — его модели); кнопка «Обновить»
  перечитывает список.
- **Чаты** — история бесед: селектор для переключения, «Удалить чат» — убрать
  из истории; в меню **⋮** — «Новый чат» и «Экспорт чата в .md…» (то же — меню
  **Файл → «Экспорт чата .md…»**).
- **Поле ввода** — Enter или «Отправить» отправляет сообщение; «Стоп» прерывает
  генерацию.

## Маршрутизация

Каждый вопрос маршрутизируется (`[strategy=...]` под ответом): `direct` для обычных
вопросов, `rag` — когда задан индекс проекта и вопрос о коде, `web` — при включённом
веб-поиске. Превью без генерации — команда `/route` в CLI (см.
[Конфигурацию](../configuration.md)).

## Агент из чата

Флажок **«Агент: файлы»** у поля ввода меняет режим: следующее сообщение
выполнит ReAct-агент с инструментами проекта вместо простого диалога. Запись файлов
доступна в Pro (см. [руководство по агенту](agent.md)).

## Встроенный браузер

Кнопка **«Браузер»** внизу справа открывает боковую веб-панель. Ссылки из ответов и
результаты веб-поиска открываются в ней — код и поисковые запросы не уходят в
облачный AI (см. [Веб-поиск](web-search.md)).

## Состояние и баннеры

Внизу окна — строка состояния: какая модель работает и готова ли она. Если
что-то недоступно (модель не скачана, Ollama не запущена при работе через неё,
расширенный поиск включён, а Docker остановлен), в чат добавляется баннер с
причиной — кнопка **«Состояние»** внизу справа открывает диагностику с кнопкой
«Исправить» (подробнее — [Решение проблем](../troubleshooting.md)).

## Эквиваленты CLI

| Действие в приложении | Команда CLI |
|-----------------------|-------------|
| Переключить модель | `/model`, настройка в конфиге |
| Новый чат | `/clear` |
| Проверить состояние | `/status` |
| Агент с инструментами | `/agent [--write] <task>` |
