# Установка

## Готовые сборки (Windows x64)

[:material-download: Страница загрузки](../../){ .md-button .md-button--primary }

**Скачайте `FluxionSetup.exe`, запустите — готово.** Права администратора не
нужны: программа ставится для текущего пользователя в
`%LOCALAPPDATA%\Programs\Fluxion`, появляется в меню «Пуск» (ярлык на рабочем
столе — по желанию) и в «Установленных приложениях», откуда её можно удалить.

| Файл | Что это |
|------|---------|
| **FluxionSetup-<версия>.exe** | Установщик программы — рекомендуется. Рядом лежит `FluxionSetup-<версия>.exe.sha256` с контрольной суммой |
| **FluxionBrowser-Lite-win64-<дата>.7z** | Та же программа без установки (портативная версия). Распакуйте и запустите `FluxionBrowserLite.exe` |

Если Windows покажет предупреждение SmartScreen: «Подробнее» → «Выполнить в
любом случае».

### Обновление

**Одним кликом.** Установленный Fluxion сам проверяет обновления раз в день,
в фоне и без сообщений, если обновления нет. Когда выходит новая версия, он
показывает, что в ней нового, и предлагает «Обновить сейчас»: скачивает
установщик, сверяет его контрольную сумму SHA256 (без неё или при
несовпадении обновление отменяется), закрывается, ставит новую версию и
запускается снова. «Пропустить эту версию» — больше не напоминать о ней,
галочка «Проверять обновления автоматически» — выключить проверку. Вручную —
**Помощь → «Проверить обновления…»**.

Портативная копия (`.7z`, `portable.txt`) обновляется вручную: кнопка ведёт на
сайт. Можно и так: скачайте новый `FluxionSetup.exe` и запустите его — он
закроет работающий Fluxion и заменит программу. Чаты, индексы документов,
настройки, модели и лицензия сохраняются — они хранятся не в папке программы.

Тихая установка (для администраторов):

```
FluxionSetup-<версия>.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

`/DIR="путь"` — другая папка установки, `/RESTARTAPP` — запустить Fluxion
после установки (так делает обновление из программы).

### Где хранятся данные

| Что | Где |
|-----|-----|
| Чаты, индексы, журналы, «Мой стиль», свой `config\config.yaml` | `%LOCALAPPDATA%\Fluxion\data` и `%LOCALAPPDATA%\Fluxion\config` |
| Модели, окружение обучения | `%LOCALAPPDATA%\Fluxion\models`, `%LOCALAPPDATA%\Fluxion\training_env` |
| Лицензия, облачная модель, каталог материалов | `%APPDATA%\Fluxion` |

При удалении программа спрашивает, удалить ли и данные из
`%LOCALAPPDATA%\Fluxion`; лицензия в `%APPDATA%\Fluxion` остаётся.

Прежние версии хранили данные в папке `data` рядом с exe. При первом запуске
новая версия один раз копирует их в `%LOCALAPPDATA%\Fluxion` (старая папка
остаётся на месте). Установщик ставит программу в новую папку и старую не
видит: перед установкой распакуйте новый `.7z` поверх старой папки и запустите
оттуда Fluxion один раз — или скопируйте папку `data` в
`%LOCALAPPDATA%\Fluxion\data` вручную.

### Портативный режим

Чтобы всё хранилось рядом с программой (например, на флешке), распакуйте `.7z`
и положите рядом с `FluxionBrowserLite.exe` пустой файл `portable.txt`: данные
и `config` будут в папке программы, как в прежних версиях.

Для QLoRA-обучения в любой сборке нужен Python 3.12 и NVIDIA GPU (6–12 ГБ VRAM).

## Требования

- Готовые сборки: **только Windows x64** — движок llama.cpp уже внутри exe
- Запуск из исходников: **Python 3.11+** + `pip install -r requirements.txt -r requirements-llamacpp.txt`
- Ollama — **опционально**, как альтернативный бэкенд (`backend: ollama`)
- Docker — опционально, только для расширенного веб-поиска через SearXNG
- Python 3.12 venv — опционально, для QLoRA-дообучения

## Windows — батники

| Батник | Что делает |
|--------|-----------|
| **`fluxion-setup.bat`** | Установка из исходников: виртуальное окружение, зависимости, встроенный движок llama.cpp, по желанию — сервер. Запускается один раз, повторный запуск пропускает установленное |
| **`fluxion-desktop.bat`** | Запуск приложения (то же, что `FluxionBrowserLite.exe`): чат, агент, RAG, веб-поиск, модели |
| `fluxion.bat` | CLI в терминале (чат, RAG, агент) |
| `fluxion-server.bat` | API-сервер на `127.0.0.1:8765` для расширения VS Code |
| `fluxion-vscode.bat` | Установка расширения VS Code |
| `fluxion-test.bat` | Тесты по группам и проверка агента на вашей модели |
| `fluxion-update.bat` | Для разработчика: обновление исходников из архива с резервной копией, откатом и пересборкой exe. Архив с той же или более старой версией отклоняется (`--force` — принять). Готовую программу обновляет `FluxionSetup.exe` |
| `fluxion-build.bat` | Пересборка exe из текущего кода, без обновления (`--lite`); если установлен Inno Setup (`winget install JRSoftware.InnoSetup --scope user`) — и установщик `dist\artifacts\FluxionSetup-<версия>.exe` с `.sha256` |
| `fluxion-release.bat` | Выпуск новой версии на GitHub: тесты, коммит, тег, релиз со сборками (для владельца) |
| `issue-key.bat` | Выпуск лицензионных ключей (для владельца) |

```
Первый запуск:
  1. fluxion-setup.bat      → установка
  2. fluxion-desktop.bat    → программа; модель — страница «Модели»

Дополнительно:
  fluxion-vscode.bat + fluxion-server.bat → расширение VS Code
  fluxion.bat               → CLI
```

Веб-поиск работает сразу встроенным способом. Расширенный поиск через SearXNG в
Docker включается в программе: меню **Правка → «Расширенный веб-поиск»**; для CLI и
сервера — `powershell -File scripts\setup_searxng.ps1`.

## Ручная установка (любая ОС)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/djonros/fluxion.git
cd fluxion

# 2. Установить зависимости (включая llama.cpp)
pip install -r requirements.txt -r requirements-llamacpp.txt

# 3. Запустить программу — мастер первого запуска предложит скачать модель
python -m desktop_browser

# CLI (модель — скачанная в программе или gguf_path в config/config.yaml):
python -m cli.app

# API сервер (опционально):
pip install -r server/requirements.txt
python -m uvicorn server.app:create_app --factory --port 8765
```

GGUF-модель можно задать и вручную в `config/config.yaml` (`backend: llama_cpp` +
`gguf_path: <путь>`) или скачать на странице «Модели». Уже имеющиеся модели Ollama
импортируются без перекачки: страница «Модели» → «Импорт из Ollama».

## Перенос на флешке

Проект полностью портативен. Скопируйте папку целиком, на новом компьютере:

```
1. Вставить флешку
2. Запустить fluxion-setup.bat (установит зависимости и движок)
3. Запустить fluxion-desktop.bat
```

Конфиги используют относительные пути — хардкод путей отсутствует.

## Проверка установки

=== "CLI"

    ```
    fluxion.bat
    ❯ /status
    ```

    Команда `/status` покажет состояние движка, модели, индекса и веб-поиска.

=== "Сервер"

    ```bash
    python -m uvicorn server.app:create_app --factory --port 8765
    curl http://localhost:8765/api/health
    ```
