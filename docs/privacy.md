# Приватность

Fluxion спроектирован так, чтобы ваш код и переписка не покидали машину.
**Мы не собираем личные данные:** ни программа, ни сайт не ведут телеметрию и
аналитику и ничего не отправляют разработчику автоматически.

[English version — Privacy Policy](privacy-en.md)

## Что остаётся на вашем компьютере

- **Диалоги и промпты** — обрабатываются локальной моделью (llama.cpp внутри
  приложения); история чатов хранится в `%LOCALAPPDATA%\Fluxion\data`.
- **Ваш код и документы** — индексы поиска лежат там же
  (`%LOCALAPPDATA%\Fluxion\data`); агент читает и пишет файлы только в
  выбранной папке проекта.
- **Модели** — GGUF-файлы в `%LOCALAPPDATA%\Fluxion\models`; можно переносить
  копированием.
- **Настройки** — `%LOCALAPPDATA%\Fluxion\config`; лицензия, облачная модель и
  каталог материалов — в `%APPDATA%\Fluxion`.
- **Лицензия Pro** — проверяется локально (Ed25519), без сервера активаций.

В портативном режиме (файл `portable.txt` рядом с `FluxionBrowserLite.exe`)
всё это хранится в папке программы. Из исходников — в папке `data` проекта.

## Когда программе нужен интернет

| Действие | Что уходит в сеть |
|----------|-------------------|
| Проверка обновлений: сама, раз в день (можно выключить галочкой «Проверять обновления автоматически»), и по кнопке **Помощь → «Проверить обновления…»** | Запрос к GitHub (`api.github.com`) о последней версии; GitHub видит IP-адрес, личные данные и содержимое программы не передаются |
| «Обновить сейчас» | Скачивание установщика и его контрольной суммы с GitHub Releases |
| Скачивание модели из каталога | HTTPS-запрос к Hugging Face (`huggingface.co`); передаются только имя файла и IP |
| Веб-поиск (встроенный, по умолчанию) | Текст поискового запроса — в DuckDuckGo; код проекта не отправляется |
| Веб-поиск (расширенный, если включён) | Запрос — в ваш SearXNG, который опрашивает поисковые системы |
| API-бэкенд (опционально, Pro) | Промпты уходят в выбранный вами облачный провайдер |
| Установка окружения обучения | PyPI / winget (кроме Full-сборки — там пак офлайн) |
| Отчёт о сбое | Ничего: кнопка «Отправить по email» открывает письмо в вашей почте, отправляете его вы |

Переписка с моделью покидает компьютер только в одном случае — если вы сами
настроили облачный API-бэкенд (Pro).

## Сайт

[djonros.github.io/Fluxion](https://djonros.github.io/Fluxion/) — статическая
страница на GitHub Pages: без учётных записей, форм, cookies, аналитики и
рекламы. Сам сайт ничего не собирает и не хранит.

При открытии страницы технические данные (IP-адрес и сведения о браузере)
получают:

- **GitHub** — хостинг (GitHub Pages) и `api.github.com`, у которого страница
  узнаёт последнюю версию для кнопок загрузки; файлы скачиваются с GitHub
  Releases. Действует [политика конфиденциальности GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
- **Google Fonts** (`fonts.googleapis.com`, `fonts.gstatic.com`) — шрифты
  страницы. Действует [политика конфиденциальности Google](https://policies.google.com/privacy).

**Покупка Pro.** Кнопка «Купить Pro» открывает письмо в вашей почтовой
программе. Если вы его отправите, разработчик получит то, что вы в нём
напишете (обычно имя и адрес почты). Адрес используется только чтобы выслать
лицензионный ключ и ответить на письмо; он никому не передаётся и не
используется для рассылок.

## Чего нет

- Нет телеметрии и аналитики — ни в программе, ни на сайте.
- Нет аккаунтов для работы с программой.
- Ничего не отправляется автоматически — ни код, ни диалоги, ни индексы.
