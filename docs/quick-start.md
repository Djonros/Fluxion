# Быстрый старт

Fluxion — десктоп-приложение для Windows: локальный AI-ассистент по вашему коду.
Модель работает на вашей машине — движок llama.cpp встроен в приложение, код и
переписка никуда не отправляются. Ни Docker, ни Ollama, ни облако не нужны.

## 1. Установите приложение

Скачайте сборку на [странице загрузки](../) и распакуйте архив в любую папку:

| Сборка | Запуск | Что внутри |
|--------|--------|-----------|
| **Lite** | `FluxionBrowserLite.exe` | Чат, поиск по коду, веб-поиск, агент. Портативно, без установки |
| **Full** | `FluxionBrowserLite.exe` | То же + офлайн-пакет обучения: окружение QLoRA ставится **без интернета** |

Размер каждой сборки указан на странице загрузки.

Установка не требуется — просто запустите exe.

## 2. Первый запуск: мастер настройки

При первом старте откроется мастер: он проверит систему и **скачает GGUF-модель с
прогресс-баром** (по умолчанию qwen2.5-coder-7b Q4_K_M, ~4.7 ГБ, с докачкой при
обрыве), затем выполнит тестовый промпт и откроет главное окно. Ничего
устанавливать не нужно: движок уже внутри exe. Любую модель из каталога можно
позже скачать, импортировать с диска или из Ollama на странице **«Модели»**.

## 3. Первый чат

Слева — панель навигации: **Чат · Проект · Агент · Обучение · Модели**.

1. Откройте страницу **Чат**.
2. Начните с кнопки-подсказки («Объясни этот проект») или напишите свой вопрос.
3. Нажмите **Отправить** (или Enter).

Под ответом видна строка `[strategy=...]` — какой маршрут выбрал Router (подробнее в
[Конфигурации](configuration.md)). История бесед сохраняется: в меню **⋮** рядом
с выбором модели — «Новый чат» и «Экспорт чата в .md…».

## 4. RAG по своему коду

1. Откройте страницу **Проект** и нажмите **Выбрать…** — укажите папку с кодом.
2. Нажмите **Проиндексировать** и дождитесь «RAG: N чанков в индексе».
3. Вернитесь в **Чат** и спросите что-нибудь о коде — ответы теперь опираются на
   ваш индекс (маршрут `rag`).

Подробности — в [руководстве по RAG](guides/rag.md).

## 5. ReAct-агент

Откройте страницу **Агент**, опишите задачу (например: «прочитай main.py и объясни,
что он делает»), при желании увеличьте лимит итераций и нажмите **Запустить** —
агент решит задачу пошагово, каждый шаг виден в логе.

- Бесплатно агент только читает: находит ошибку и объясняет её.
- Флажок **«Разрешить запись файлов (Pro)»** (в «⚙ Дополнительно») позволяет агенту
  править код и проверять правки тестами. Перед первой правкой он делает снимок
  проекта, не трогая ваши несохранённые изменения, — всё можно откатить.
- Быстрый вариант из чата: включите флажок **«Агент: файлы»** у поля ввода — тогда
  сообщение уйдёт агенту с инструментами проекта.

Подробности — в [руководстве по агенту](guides/agent.md).

## 6. Дообучение (Pro)

Страница **Обучение**: QLoRA-дообучение модели на вашем датасете `.jsonl`,
готовая модель автоматически появляется в списке моделей чата.

1. Если окружение обучения не найдено — нажмите **«Установить окружение обучения»**
   (программа сама проверит Python 3.12 и развернёт venv; в Full-сборке пак
   ставится офлайн из `training_pack\wheels`).
2. Выберите датасет, пресет VRAM и параметры, нажмите **«Начать обучение»**.

Требуется NVIDIA GPU (6–12 ГБ VRAM). Подробности — в
[руководстве по дообучению](guides/finetune.md).

## 7. Веб-поиск

Работает сразу, встроенным способом, — Docker не нужен. Расширенный поиск через
SearXNG (больше источников, нужен Docker Desktop) включается в меню **Правка →
«Расширенный веб-поиск (SearXNG в Docker)»**. Подробнее — [веб-поиск](guides/web-search.md).

## Если что-то не работает

Кнопка **«Состояние»** внизу справа показывает диагностику (движок, модель,
веб-поиск, индекс) и предлагает кнопку **«Исправить»**. При деградации в чате
появляется баннер с причиной. Полный список случаев — в
[Решении проблем](troubleshooting.md). Частые вопросы — в [FAQ](faq.md).

## CLI-режим (для тех, кто любит терминал)

Запустите `fluxion.bat` или `python -m cli.app` — тот же движок в REPL-форме:

| Команда | Описание |
|---------|----------|
| `/help` | Список команд |
| `/status` | Состояние модели, индекса и веб-поиска |
| `/model` | Текущая модель |
| `/index [путь]` | Проиндексировать папку |
| `/search <запрос>` | Поиск по проиндексированному коду |
| `/rag on\|off\|clear` | Принудительно включить или выключить поиск по коду |
| `/route <запрос>` | Показать маршрут вопроса без ответа |
| `/web <запрос>` | Веб-поиск |
| `/webclear` | Очистить кэш веб-поиска |
| `/agent [--write] [--iter N] <задача>` | Агент; `--write` — правка файлов (Pro) |
| `/rollback [путь]` | Отменить правки последнего запуска агента |
| `/adapters list\|info\|register\|delete\|switch` | Адаптеры LoRA |
| `/license status\|activate <ключ или файл>\|deactivate` | Лицензия |
| `/theme dark\|light` | Тема оформления |
| `/clear` | Очистить историю диалога |
| `/exit` | Выход |
