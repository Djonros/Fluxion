# Частые вопросы

## Общие

**Мой код уходит в облако?**
Нет. Модель работает на встроенном движке llama.cpp прямо на компьютере, индекс
проекта хранится локально. В интернет уходят только **поисковые запросы**, когда
Fluxion ищет в сети: встроенный поиск отправляет текст запроса в DuckDuckGo,
расширенный — в ваш SearXNG, который сам опрашивает поисковые системы. Код
проекта при этом не отправляется. Отчёт о сбое программа не отправляет сама: в
окне ошибки есть кнопки «Копировать отчёт» и «Отправить по email» — письмо
уходит из вашей почты, только если вы его отправите.

**Какие ОС поддерживаются?**
Готовые сборки — Windows 10 и 11, 64 бит. На Linux и macOS Fluxion запускается
из исходников (см. [Установка](install.md), «Ручная установка»).

**Какая модель используется?**
По умолчанию Qwen2.5-Coder 7B (Q4_K_M, 4,7 ГБ). Бесплатно также доступны 3B для
слабых компьютеров и BGE-M3 для поиска по коду; с Pro — 7B в точности Q8_0, 14B
и 32B. Можно импортировать свой GGUF с диска или модели из Ollama без повторной
загрузки. Подробнее — [Модели](guides/models.md).

**Нужны ли Ollama или Docker?**
Нет. Ollama можно подключить по желанию как альтернативный движок, а Docker
нужен только для расширенного веб-поиска через SearXNG, который включается
вручную (меню **Правка**).

**Где хранятся мои данные?**
Всё на вашем компьютере:

| Что | Где |
|-----|-----|
| Модели | `%LOCALAPPDATA%\Fluxion\models` |
| История чатов, индекс проекта, окружение обучения | папка `data\` рядом с программой |
| Лицензия | `%APPDATA%\Fluxion\license.key` (при запуске из исходников — `data\license.key`) |
| Настройки окна и выбор расширенного поиска | профиль пользователя Windows |

## Сборки

**Чем отличаются Lite и Full?**
Lite — программа целиком: чат, поиск по коду, веб-поиск, агент, модели. Full
добавляет офлайн-пакет для дообучения (PyTorch с CUDA, unsloth и другие
библиотеки): окружение обучения ставится кнопкой на странице «Обучение» без
интернета. Размеры — на [странице загрузки](../).

**Нужно ли что-то доустанавливать?**
Для чата, поиска и агента — нет: движок внутри сборки. Для дообучения нужны
Python 3.12 (программа предложит установить его через winget) и видеокарта
NVIDIA.

**Работает ли Fluxion без интернета?**
Да: чат, поиск по коду и агент работают полностью локально. Интернет нужен для
первой загрузки моделей, веб-поиска и установки окружения обучения (кроме
сборки Full).

## Обучение

**Какая видеокарта нужна?**
NVIDIA: пресет `low` — от 6 ГБ видеопамяти (unsloth), `standard` — 8–12 ГБ
(HF peft и trl).

**Дообучение бесплатно?**
Нет, это функция Pro. Ключ активируется в **Помощь → Лицензия…** — см.
[Лицензия Pro](guides/licensing.md).

**Куда девается обученная модель?**
Обучение создаёт адаптер LoRA, объединяет его с базовой моделью и собирает
готовую модель (GGUF). Она появляется в списке «Модель» в чате под названием,
указанным в «Дополнительных настройках». Для сборки GGUF нужна папка llama.cpp
в переменной окружения `LLAMA_CPP_DIR`; без неё сохраняется адаптер, а модель
можно собрать позже — см. [дообучение](guides/finetune.md).

## Проблемы

**Программа пишет «Недоступно: …» при старте.**
Нажмите «Состояние» внизу справа — там причина и кнопка «Исправить». Разбор
всех случаев — [Решение проблем](troubleshooting.md).
