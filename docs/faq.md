# FAQ

## Общие

**Мой код уходит в облако?**
Нет. Движок llama.cpp встроен в приложение и работает локально, индекс проекта —
в локальной ChromaDB, веб-поиск идёт через ваш SearXNG. Отчёт о падении
отправляется только если вы сами нажали «Отправить» в диалоге.

**Какие ОС поддерживаются?**
Готовые сборки — Windows x64. На Linux/macOS проект запускается из исходников
(см. [Установка](install.md), «Ручная установка»).

**Какая модель используется?**
GGUF-модели из встроенного каталога (страница «Модели»): по умолчанию
`qwen2.5-coder-7b-instruct` Q4_K_M; есть облегчённая 3B и эмбеддер bge-m3 для RAG.
Можно импортировать свой GGUF с диска или из существующего Ollama без перекачки.

**Где хранятся мои данные?**
Всё локально: индекс и venv обучения — в `data\`, история чатов и настройки — в
профиле пользователя, лицензия — в `data/license.key`. Папку можно перенести.

## Сборки

**Чем отличаются Lite и Full?**
Lite (~130 МБ) — чат, RAG, веб-поиск, агент. Full (~2.9 ГБ) добавляет
`training_pack\wheels`: CUDA-стек обучения (torch cu126, unsloth и др.), который
ставится кнопкой на странице «Обучение» без интернета.

**Нужно ли что-то доустанавливать в Full?**
Для обучения нужен только Python 3.12 и NVIDIA GPU — программа предложит
установить Python через winget. Для чата/RAG доустанавливать ничего не нужно:
движок уже внутри сборки.

**Работает ли Fluxion без интернета?**
Да: чат, RAG и агент полностью локальны. Интернет нужен для первого скачивания
моделей, веб-поиска и установки окружения обучения (кроме Full-сборки).

## Обучение

**Какой GPU нужен?**
NVIDIA: пресет `low` — около 6 ГБ VRAM (unsloth), `standard` — 8–12 ГБ
(HF peft+trl).

**Дообучение бесплатно?**
QLoRA-дообучение — функция Pro (см. [Лицензия Pro](guides/licensing.md)):
активируйте ключ кнопкой «Лицензия» слева внизу.

**Куда девается обученная модель?**
Пайплайн делает адаптер → merge → GGUF: готовая модель появляется в списке моделей
чата автоматически.

## Проблемы

**Приложение пишет «Недоступно: …» при старте.**
Это баннер Zero Silence: нажмите «Состояние» слева внизу — там причина и кнопка
«Исправить». Разбор всех случаев — [Решение проблем](troubleshooting.md).
