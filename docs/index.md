**AI-помощник для кода, текстов, документов и КОМПАС-3D, который работает на вашем компьютере.**

Fluxion — чат, агент, ответы по вашим документам, письма вашим стилем, отчёты
и нормоконтроль сборок КОМПАС-3D и чертежей AutoCAD, дообучение модели — в
одной программе для Windows. Модель работает на встроенном движке llama.cpp:
файлы не покидают компьютер, ничего дополнительно ставить не нужно.
