**Помощник для Python-кода, который работает на вашем компьютере.**

Fluxion — чат о коде, агент, поиск по проекту и дообучение модели в одной
программе для Windows. Модель (Qwen2.5-Coder) работает на встроенном движке
llama.cpp: код проекта не покидает компьютер, Ollama и Docker не нужны.

[:material-download: Страница загрузки](../){ .md-button .md-button--primary }
[:material-rocket-launch: Быстрый старт](quick-start.md){ .md-button }

## Что умеет

| Возможность | Бесплатно | Pro |
|---|:---:|:---:|
| Чат о коде с учётом проекта, поиск по коду по смыслу | ✅ | ✅ |
| Веб-поиск: встроенный; SearXNG в Docker — по желанию | ✅ | ✅ |
| Агент: находит файлы, читает код, запускает тесты, объясняет ошибки | ✅ | ✅ |
| Агент правит файлы сам и проверяет правки тестами | — | ✅ |
| Модели 7B и 3B; движки llama.cpp и Ollama | ✅ | ✅ |
| Расширенный каталог моделей: 7B Q8_0, 14B, 32B | — | ✅ |
| Дообучение QLoRA, пресеты обучения из файла | — | ✅ |
| Облачные модели через API | — | ✅ |
| CLI, расширение VS Code, локальный API-сервер | ✅ | ✅ |
